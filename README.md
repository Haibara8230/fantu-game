# 凡途 · 修仙纪事

Godot 4 / GDScript / Windows 单机。同一个修仙世界持续运转，玩家在几百年的岁月里修炼、探索与交际。当前是 M0 重整后的原型，尚非完整成品；方向与里程碑见 `docs/ROADMAP.md`，规则基线见 `docs/DESIGN_BASELINE.md`。

## 开始游玩

双击 `play.cmd`。双击 `preview_art.cmd` 可直接进入人物斗法试演，使用独立存档，不会覆盖正常旅程。项目内已准备官方 Godot 4.7.2 便携版，位于忽略目录 `.tools/godot`，没有修改系统安装。
双击 `edit.cmd` 打开编辑器，也可从 Godot 导入 `project.godot`，按 F6/F5 运行。

重新获取引擎时使用 [Godot 官方 Windows 下载页](https://godotengine.org/download/windows/)，选择标准版，无需 .NET。
从仓库获取项目不会包含便携引擎，可将标准 Windows 版解压到 `.tools/godot`，或自行在 Godot 中导入项目。

## 当前玩法

时间按日计算（每月 30 天、每年 12 个月），只有交互行为和赶路推进日期。各行为耗时见 `data/world.json` 的 `actions` 与 `routes`。

1. 青云山修炼，每次 30 日获得 18 修为；休整恢复气血与灵力。
2. 前往落霞谷采集灵草，或挑战妖狼获得资源。
3. 在云溪坊市出售灵草，每株 8 灵石；花费 60 灵石购买筑基丹。交易不耗时日。
4. 返回青云山，消耗 100 修为、一枚筑基丹，闭关 90 日突破。
5. 筑基后可平定赤鳞妖蟒。这是一件地区大事：妖蟒伏诛后落霞谷重归安宁，世界继续运转。

闭关可选 1 个月、3 个月或 1 年，修为按实际经过的天数计算；任何地点都可以停留 1 日或 10 日等候时机。已知的约定开场、寿元将尽时，闭关和停留会提前结束。寿元耗尽即此生终结，可读档继续。

世界按日历运转：坊市的药铺掌柜沈墨、坊间传言、宗门请柬、历元五年春的云溪特殊拍卖（筑基持请柬，或经沈墨引荐入场）、三年一度的云溪夜市、十年一度的外门小比，都由地点、日期和条件触发；错过的事件会过期，并留下后续传闻。事件定义见 `data/events.json`。

斗法神通：御剑诀（免费攻击）、离火术（高伤害）、回春诀（治疗）。
守御恢复灵力、减半本回合所受伤害。冷却在有效行动后推进。
落败后回到青云山，最多损失 10 灵石；可休整后继续。撤退耗时 30 日。

## 存档与操作

- 游戏开始后，每次有效行动自动保存，标题界面的“继续旅程”读取自动存档。
- F5 / “保存”：手动存档。F9 / “读取”：读取手动存档，不会被普通自动存档覆盖。
- 斗法中 1 / 2 / 3 施展神通，空格守御；全部操作也有鼠标按钮。
- 存档在 Godot 的 `user://saves`（Windows 通常位于 `%APPDATA%/Godot/app_userdata/凡途 · 修仙纪事/saves`）。
- 自动与手动分别保留两代；最新一代损坏时尝试读取前一代。战斗状态和随机数状态都包含在存档中。
- 格式含版本号，目前版本 3。旧版本存档读取时先逐版本迁移（`scripts/core/save_migration.gd`），再校验；`tests/fixtures/` 保存各旧版本的真实样例。
- 随机数分为斗法与世界两路，均写入存档；编年史以事件 ID、参数和日期保存，显示时生成文字。

## 项目结构

- `data/world.json`：地点、路线、境界、行为耗时、敌人、神通与基础数值。
- `data/chronicle.json`：编年史文字模板。
- `data/events.json`：地点、日期与条件触发的事件。
- `scripts/core/events.gd`：事件引擎与到期调度。
- `scripts/core/content.gd`：内容加载与配置校验。
- `scripts/core/session.gd`：游戏状态、统一时间推进、修炼、交易、突破，与界面无关。
- `scripts/core/combat.gd`：斗法规则。
- `scripts/core/calendar.gd`：历法与日期文字。
- `scripts/core/chronicle.gd`：结构化编年史。
- `scripts/core/save_migration.gd`：存档版本迁移。
- `scripts/core/save_store.gd`：本地存档与备份恢复。
- `scripts/ui/main.gd`：桌面界面与输入。
- `scripts/ui/landscape.gd`：地点页暂用的占位山水。
- `scripts/presentation/`：角色姿态、技能特效、战斗事件演出。
- `data/art.json`：美术图集与姿态配置。
- `docs/ART_ASSETS.md`：选定美术、完整生成提示词与当前能力边界。
- `tests/`：真实引擎下的玩法流程与界面检查。

## 检查

运行 `check.cmd`，执行核心规则、无界面场景与演出行为测试。
界面逻辑检查使用：
`godot --headless --path . --script res://tests/ui_smoke.gd`
需要直接看效果时，由用户启动 `preview_sects.cmd`。
历史截图输出在 `builds/previews`。自动测试默认全部使用 --headless 在后台运行，不弹出游戏窗口。测试存档使用 `.godot` 内的隔离目录，不会修改玩家存档。

## 门派动作与特效

五套门派流派、十五种神通已接入斗法。青云山的“研习传承”可切换流派；`preview_sects.cmd` 提供我方和对手流派选择与重置。三才剑阵和飞叶千刃分三段命中，显示伤害总和与结算一致。详见 `docs/SECT_EFFECTS.md`。

## 后续开发

按 `docs/ROADMAP.md` 的里程碑推进：M0、M1 已完成；接下来是 M2 节点地图与首个区域，M3–M4 完成并打磨前 5 小时样板，之后逐段扩展。

战斗已有原创二维手绘人物、妖狼与妖蟒、竹林山谷背景，并有出招、施法、受击与守御演出。当前采用关键姿态图集与补间，尚无完整骨骼绑定；地点页仍用占位美术，尚无音效、角色走动、自由地图、NPC 模拟、正式剧情或独立 exe 发行包。
发布独立 Windows 程序时需要同版本导出模板与 Windows 导出预设。当前启动器运行项目源码，便于持续开发。

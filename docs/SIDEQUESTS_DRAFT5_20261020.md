**等级的影响**：月俸与兑换的上限、可得功法的最高品阶、秘境与论道的名额、仇家的分量。
**气运与升降**：每宗有气运（0～100），由宗门大事、弟子名次、资源得失决定；天机阁「宗门榜」每十年按气运公示升降（见第三部分）。
**长老与宗主**：元婴可任长老（一座峰、带弟子、管一项产业）；元婴后期可经宗门大事被推为宗主。散修元婴后可在占下的灵地开宗立派。
**拜入规则**：一生只正式拜入一个宗门（世家联姻、客卿不算拜入）；叛出会被原宗门追讨；宗门弟子不能做别宗客卿。

# 三　天机阁与榜单

## 3.1 天机阁

- **是什么**：天南最强的宗门，中立，不争地盘。阁主「天机子」化神后期，天南无人敢惹。阁中修推演之术，能算一地一人的气数，靠卖情报与颁榜立身。
- **为什么人人在乎它的榜**：天机阁的名次就是天南公认的身价。上榜的人，宗门给资源、商铺给面子、大宗来招揽；落榜的人，原本巴结你的人会走。
- **颁发与修改**：
  - 每十年大修一次，天机阁的「执笔」在各城张贴。
  - 平时有大战绩（秘境一战、宗门之战、斩了榜上的人），天机阁会随时「批注改名」，几天之内各城的榜就变了。
  - 天机阁也会算错、也会被收买：这是「改榜」支线的引子。
- **与主线**：天机阁的推演算不透照川城，阁主为此找过晏无咎。真相公开或保住后，天机阁的态度跟着变（不改主线，只加对话）。

# 四　秘境

## 4.1 通用规则

- **限时**：每个秘境开放时长不同（一月到一年），时间到了没出来的人困死（可用保命符或阵盘逃出，有代价）。
- **名额**：宗门按等级分名额；散修靠买、抢、顶名，或跟人进。
- **多方同场**：每处秘境都有几方势力，各有所图；组队可能被出卖。
- **分层夺宝**：越深越好，也越险；拿了好东西会被盯上。
- **出口截道**：带的东西越多，越可能有人在出口等你。
- **上榜**：秘境里的斗法与夺宝，天机阁会批注进榜。

## 3　鬼市夜灯（新）

- **鬼市**：云溪城西废码头，每月十五子时开，天亮散。人人戴面具，不问来历。主人「灯婆」，金丹后期，鬼市里谁动手谁死。
- **能做的事**：
  - 赌宝：买没开封的古修储物袋、蒙着布的旧兵器。神识越高，看出的越多（神识决定「看出几成」）；看走眼就是亏钱。
  - 销赃：截杀、秘境里得来的东西，在明面上卖会被认出来；鬼市收，但价低。
  - 雇凶与被雇：可以出钱雇劫修截杀仇家；也可以接单去截别人（凶人榜记名）。
  - 黑拍：每季一场，拍禁物（魔功残卷、夺舍秘术、他人的洞府钥匙）。
- **财不露白**：鬼市里出手太阔，散场后就有人跟着你。灯婆只管市里，不管市外。
- **长线**（金丹）：五宗要联手扫平鬼市，请你做内应；灯婆请你帮她守市。
  - 帮五宗：鬼市覆灭，五宗记你一功，鬼市里的散修恨你。
  - 帮灯婆：守住鬼市，你成了鬼市的「二灯」，往后赌宝、销赃都优待，凶人榜挂名。
  - 两头吃：把两边的底都卖给对方，自己趁乱抄了鬼市的库房（最赚，也最危险：两边都可能发现）。
- **灯婆的秘密**：她是陆家当年被逐出的长女，鬼市的账本记着陆家半数生意的黑底子（接「陆家夺嫡」）。

## 分类重绘约束

下面是根据实际参考图归纳的制作标准，属于本项目后续重绘要求，不是对原游戏制作参数的断言。

| 类型 | 对应原图 | 后续重绘重点 |
|---|---|---|
| 主角／NPC／半身像 | 已确认 C 版；Steam 15、18；原有青蛇真人截图 | 简练的成人造型、清楚五官、整体发束、主要衣褶。保留各人的年龄、脸型、发式和身份；不可把全图池都画成同一种瘦长脸。 |
| 角色动作图集 | 主角 C 版＋Steam 01、03、05 的实际战斗比例 | 同一角色各动作保持身份、服饰、比例；保留原图集格子、帧序、朝向、脚底基线、透明度和安全边距。 |
| 妖兽 | Wiki 三兽；Steam 白狐、章鱼 | 先确定外轮廓和身体结构，再按组表现毛、鳞、羽；原图仍有局部细节和体积，不能统一改成只有两块颜色的符号。 |
| 地点整屏／建筑／自然场景 | Steam 00、06、01、05；室内剧情截图 | 大块前中后景、概括植被、建筑清楚轮廓。背景可有柔和色彩过渡和简化笔触；避免照片材质、密集碎纹、电影式强光和写实景深。 |
| 区域地图／洞府地图 | Steam 02、04、11 | 概括山形、林团、海面和地标；固定俯视关系与功能留白。继续保持本项目地点坐标、比例、路线与文字叠加约定。 |
| 斗法背景 | Steam 01、03、05 | 地面宽阔、站位可读；前景不遮挡角色，背景层次服从战斗主体；不增加影响读数的高对比碎景。 |
| 草药／丹药／材料／法宝／书籍 | Wiki 两件小图；Steam 09、15 | 优先小尺寸剪影和物品差异，保留必要材质高光与明暗。原作丹药、晶石等有适度体积表现，不能照搬人物的无高光要求。 |
| 神通／状态／五行图标 | Steam 01 的技能区、Steam 13 | 清楚的剑、手、风等图形语言，颜色传达属性；减少无意义装饰。程序 SVG 继续改生成脚本，不能用生成位图强行替换整个矢量体系。 |
| 界面边框／按钮／卷轴 | Steam 07、09、10、13、14、16、17 | 青绿功能区、纸色内容区、木色结构与暖金焦点；装饰让位给文字与状态。仅参考材质和画法，保留本项目数据与信息架构。 |
| 打坐／丹炉／灵田 | Steam 09、11、13；灵田攻略图 | 轮廓化炉体、打坐人物和云气，功能焦点集中；种植场景避免把格子和文字烘进环境图。 |
| 事件／突破／剧情插图 | Steam 08、12、13；室内剧情截图 | 本轮能直接确认题字、云形、人物剪影、对话场景的表现。对没有直接原图对应的复杂剧情插画，先做同类样张比较，不把“电影感 CG”当作已证实的原作标准。 |
| 战斗特效／动画 | Steam 01 的屏障、05 的战斗画面 | 静态画面仅支持形状、颜色、透明度、遮挡关系的观察；完整帧数、运动节奏和时长尚需原作视频或实际运行参考。 |

## 后续执行与验收

1. 每类选用同类原作原图为主要画风参考，现用素材负责内容／身份；人物再加入已确认 C 版。不要只写“觅长生风格”后让模型自行猜测。
2. 先做该类别的“原作参考／现用素材／重绘结果”对比样张，以实际显示比例观察轮廓、色块、细节密度、明暗和主体留白，再展开该类批次。
3. 新成品先进入 D:/fqh/flash/.tmp/ 的版本化文件；保留原图、完整提示词、输入参考、尺寸和透明度记录。
4. 接入时只修改表现资源和必要的美术配置。保留图集、地图节点、物品数据、游戏规则和玩家存档的约定。
5. 自动导入与游戏回归必须 --headless；检查脚本错误与日志，不能只看退出码。人物、图标和场景逐张读取文件做视觉检查，不打开可见游戏窗口。
6. 本轮尚未批量生成或替换任何游戏资源；参考收集与图像排版没有启动 Godot。

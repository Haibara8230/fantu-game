# 门派动作与特效

本轮新增五套原创门派流派，在既有二维手绘人物上完善招式、法术、护体与受击表现。门派名称暂定，可继续调整。

| 门派 | 三种神通 | 动作与特效 |
|---|---|---|
| 青云剑宗 | 御剑诀、三才剑阵、断月斩 | 收剑蓄势、前倾刺剑；逐道飞剑命中、弧形剑气、锋利斩痕与轻后仰 |
| 赤霄门 | 火萤诀、离火术、焚天印 | 结印聚焰；火萤、火流、落地火印、爆燃、余焰与较强冲击 |
| 长青谷 | 青藤刺、回春诀、飞叶千刃 | 指诀引灵；藤蔓穿行、叶刃分批命中、叶片环绕和绿色治疗 |
| 沧澜阁 | 沧浪诀、寒霜刺、灵泉引 | 推掌时轻提身；水波、冰晶、冰片碎裂和向上回流的灵泉 |
| 玄岳宗 | 碎岩掌、地脉冲、玄岩护体 | 沉身踏地、结印；破土岩柱、飞散碎石、较重停顿和石甲护体 |

每门派另有对应的通用守御演出：环剑、火环、叶阵、水幕、六方石甲。
同门反击使用所选对手门派的基础神通；妖狼与妖蟒保留扑击。
岩柱、爆燃不是冰冻/灼烧等持续状态机制；这轮实现的是对应法术的动作与反馈。

## 游戏里如何体验

- 正常旅程：回到青云山，在“研习传承”中选择流派，斗法技能与数字键 1/2/3 随之切换。
- 双击 preview_sects.cmd（原 preview_art.cmd 也可）：进入独立门派试演。
- 试演顶部可分别选择我方和对手门派；切换或“重置试演”会恢复气血、灵力和对手。
- 试演角色保留 20 点伤势，方便观看治疗恢复。
- 空格是通用守御，各门派有不同护体形态。玄岩护体另会恢复气血。
- 演出期间无法再次施法、切换门派、旅行或读档。

## 结算与存档

- 三才剑阵、飞叶千刃是三个命中段，显示伤害分段相加等于一次技能的实际结算，对手只反击一次。
- 血条逐段推进，最后一段与规则的最终气血一致。
- 每道剑气或每批飞叶到达目标时再触发命中、闪光、跳字与后仰。
- 重型法术增加前摇、停顿和位移，落点岩柱、火印在命中后短暂保留。
- 存档版本仍为 1；旧档缺少 sect 时默认散修，缺少 opponent_sect 时默认青云剑宗。
- 旧档仍保留御剑诀、离火术、回春诀组合。新技能的冷却与门派信息正常保存。

## 维护

- data/world.json：门派、技能、资源消耗、冷却、连击次数。
- data/vfx.json：技能表现、颜色、前摇、投射时长、命中反馈、停顿、位移。
- scripts/presentation/effect.gd：可调节的二维绘制特效。
- scripts/presentation/battle_stage.gd：播放规则输出的事件，不修改伤害规则。
- tests/sect_smoke.gd：覆盖全部十五种神通、旧档兼容、技能权限、显示伤害与实际伤害一致。

测试默认全部 --headless 在后台运行，不弹出窗口。最终效果可由用户通过试演启动器查看。

人物当前仍使用原有六种关键姿态加补间；本轮没有制作五套独立服装或完整骨骼动作，也没有加入门派入门任务与世界关系。特效保持二维手绘方向，由 Godot 原生绘制与动画生成，未新增位图资源。

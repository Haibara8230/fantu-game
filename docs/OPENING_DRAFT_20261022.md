# 开局改版设计稿：仿《觅长生》按点数逐页挑选

日期：2026-10-22。用户已定：完全按觅长生做法（去掉随机感应）、三档难度、灵根自选属性与品类；点数 10／20／40 合适，缺陷按轻重返还，一部分天赋限定对应灵根，一部分体质改由剧情获得，页面分类照此。已实现（`scripts/core/opening.gd`、`data/opening.json`、`scripts/ui/welcome_screen.gd`）；下面各页的清单是初稿，实际以 `data/opening.json` 为准。

## 做法

- 先选难度，得到天赋点；之后逐页挑选，**每页恰好选一项**，每页都有一个不花点的「平平无奇」。
- 正面的项花点，缺陷返还点数；剩下的点数可以不用完，开局后不再有用。点数不够时，贵的项不能选。
- 价格按现有天赋的品级：白 1、绿 3、蓝 6、紫 10、橙 15、红 22；缺陷按轻重返还 1～4 点（`opening.json` 的 `refunds`）。
- 五行亲和、五行之体、太阴／太阳／青帝木／坤元土之体、剑骨、先天剑体、炎心、冰魄，以及畏寒、畏火等五行缺陷，只在有对应灵根时出现；阴阳同体要水、火两行都有（`root_bound`）。换灵根时，不再合适的已选项自动取消。
- 改由剧情获得、开局不能选（`earned`）：五种道脉（在落霞谷灵眼突破成功时，按第一行灵根得对应道脉）、先天剑胎（万剑冢阙光一事了结时）、百毒不侵（长青谷「泽心旧园」找到老药园时）。残魂扰神只由残魂夺舍失败留下，也不在开局。
- 出身带开局物品（不改剧情）：天赋的 `start`，如商贾多带灵石、修真家族（新增，绿）带随灵根的黄阶心法玉简、铁匠之后带凡铁剑与青钢锭；提示里写「开局带」，总览写「开局所带」。
- 最后一页填道号，看一遍所选与资质（沿用现有资质评分），踏入仙途。可以随时翻回前面的页改。
- 不变的：天赋库与效果、NPC 生成仍用随机天赋表、后天天赋（洗髓玉露等）仍从剧情与机缘得到、红橙天赋各自的天赋剧情照旧触发；旧存档不受影响，只有新开局用这套流程。

# 新大纲美术影响评审

日期：2026-10-19。

依据：[游戏大纲](GAME_OUTLINE.md)，并对照现有 `data/world.json`、`data/art.json`、`data/npcs.json` 及 `assets/art/`。旧世界重构方案仅作历史参考；本评审和生图清单不证明内容已经实现，实际接入以当前代码和数据为准。

## 结论

本次按新大纲调整题材、空间用途、人物经历与交付顺序。各类图继续沿用原分类风格、确认样张及验收要求。需要更新的是世界布局、青云规模、城市组织、主线视觉和开局内容；通用道具、怪物、面板和生活设施先按实际用途复用。逐阶段制作范围见 [生图内容说明](../art_sources/refresh_20261019/CONTENT_PLAN.md)。

照川城、温照衡等已在新大纲定稿；晏无咎姓名与城徽造型等仍待确认。地图标签、路线、交互和状态独立于底图，不将名称烧进背景或招牌。

## 推荐制作顺序

1. 先定总体地图关系、青云小宗尺度，以及镜中旧城的一套视觉母题。
2. 完成青石镇至云溪夜宴的可玩开局：云溪公共区域、同辈初见、集会、拍卖异象、潜龙会、陆府夜宴。
3. 优先补青石镇和五城客栈静房，再随首段修行补青云日常、散修洞府、一个外城、一个代表传承及突破筹划界面。
4. 筑基篇补探索、试剑崖、历练帖与天南大比，并建立守川司及晏无咎身份；之后逐城扩展古境内部、海域、照川城和结局。

本轮不建议先把五城、全部成长立绘和所有结局一次性画完。按新大纲第16节的内容批次交付，第18节的待定细节随可玩切片校准。代表传承表现以第6.3节的水金连击、吸灵气与遁速／撤离为准，不沿用旧方案的蓄势／反击机制。

# 新大纲美术影响评审

日期：2026-10-19。

依据：[世界与剧情重构方案](WORLD_STORY_REWRITE_20261019.md)，并对照现有 `data/world.json`、`data/art.json`、`data/npcs.json` 及 `assets/art/`。新大纲仍是设计方案；本评审不表示相关内容已经实现，不修改正式资源。

## 结论

美术工作的重点需要从“统一画风”转向“先适配新内容，再统一画风”。真正需要大改的是世界地图、青云规模、城市组织、主线视觉和开局事件。新增同辈、海域、古境内部属于补建资源；通用道具、怪物、面板和生活设施通常可以继续沿用。

城市、人物、代表传承等暂拟名称在内容定案前，不宜直接烧进背景、招牌或不可修改的装饰文字。地图标签、路线、交互和状态尽量独立于底图。

## 推荐制作顺序

1. 先定总体地图关系、青云小宗尺度，以及镜中旧城的一套视觉母题。
2. 完成青石镇至云溪夜宴的可玩开局：云溪公共区域、同辈初见、集会、拍卖异象、潜龙会、陆府夜宴。
3. 随首段修行补齐青云日常、散修洞府、一个外城、一个代表传承及突破筹划界面。
4. 后续逐城扩展，再制作古境内部、海域、旧城和结局。普通修士、日常陈设与野外发现随实际内容补充。

本轮不建议先把五城、全部成长立绘和所有结局一次性画完。大纲第17节与第18节仍需随可玩切片校准，美术应以已确定的内容与实际使用场景为单位交付。

# 第二章 开局与引导

## 2.1 标题界面

游戏打开时是标题界面：大字「凡 途」，副题「一介凡身，问道长生。」下面一行小字「历元元年 · 青云山外门 —— 修炼、游历、结交，在流转的岁月里寻求长生之道。」

标题界面上有：

- **道号输入框**：最多 16 个字。这是玩家角色的名字，资料卡、编年史、结局画面都用它；左上角的印章取它的第一个字。
- **感应结果**：灵根（例如「灵根 · 金木水（修炼 ×1.00）」）、资质评级、先天天赋（每个天赋是一枚带颜色的小签，鼠标停留可看效果）。
- **重新感应（余 N 次）**：再测一次灵根与天赋。每段新旅程只能重测 5 次，用完就只能接受当前结果。
- **跳过入门指引（执事堂、传功堂直接开放）**：只有在本机完整走完过一次入门之后才会出现。
- **踏入仙途**：以当前的道号、灵根与天赋开始新旅程。
- **继续旅程**：读取最近的存档（自动存档与手动存档中较新的一份）。
- **返回当前旅程**：游戏中途回到标题界面时出现。
- 底部一行说明：开发版 · Windows 单机 · 本地存档；二维手绘角色 · 施法演出 · 命中与受击反馈。

## 2.2 灵根

灵根决定一个人修炼的快慢，也决定斗法时更容易抽到哪种灵气、哪些功法参悟得更快、哪些神通更有威力。五行是金、木、水、火、土。灵根按含有的元素个数分级，越纯修炼越快：

| 灵根 | 元素数 | 出现几率 | 修炼速度 | 资质分 |
|---|---|---|---|---|
| 天灵根 | 1 | 5% | ×1.8 | 12 |
| 双灵根 | 2 | 20% | ×1.4 | 8 |
| 三灵根 | 3 | 35% | ×1.0 | 5 |
| 四灵根 | 4 | 25% | ×0.75 | 3 |
| 伪灵根 | 5 | 15% | ×0.5 | 1 |

灵根的作用遍布各个系统：

- **闭关**：修炼速度直接乘上去。三灵根在心境充足、心神平和时，每 30 日闭关约得 60 修为；天灵根约 108；伪灵根约 30。
- **斗法**：每回合抽灵气时，灵根所含元素的权重是 3，其余元素是 1。三灵根的人抽到自家三种灵气的几率合计约八成。
- **神通威力**：神通的属性与灵根相合时，威力再 +10%。
- **参悟**：功法的属性与灵根相合时，参悟耗时少两成。
- **突破**：运转的心法与灵根同属性，筑基时成功率 +5。

## 2.3 天赋

每人出生自带天赋（也可能一个都没有）。天赋参照《鬼谷八荒》的先天气运，分六个等级，级差极大：

| 等级 | 颜色 | 收益倍数 | 种数 | 资质分 | 举例 |
|---|---|---|---|---|---|
| 寻常 | 白 | ×1 | 90 | 1 | 勤勉（修炼 +5%）、健步、能言、农家子弟 |
| 不凡 | 绿 | ×1.5 | 75 | 3 | 专注（修炼 +15%）、静心、将门之后、金灵亲和 |
| 出众 | 蓝 | ×2 | 60 | 6 | 一心向道（修炼 +36%）、过目不忘、剑心、锐金之体 |
| 稀世 | 紫 | ×3 | 40 | 10 | 修行奇才（修炼 +84%）、丹体、道心坚定、庚金道脉 |
| 绝世 | 橙 | ×5 | 20 | 15 | 先天道体、气运之子、剑骨、混元灵体、九窍玲珑心 |
| 天命 | 红 | ×8 | 10 | 22 | 仙人转世（修炼 +400%）、天命之人、混沌灵体、天妒英才 |

此外有 **40 种先天缺陷**（体弱多病、心浮气躁、短命相、路痴、招灾等），每种资质分 −2。还有几种只能由机缘赐予、生来不会有的天赋：前辈遗泽、顿悟余韵、生死历练；以及一种只能由机缘留下的缺陷：残魂扰神。全部天赋与缺陷见附录《天赋与缺陷全表》。

### 2.3.1 天赋怎样起作用

天赋不写专门的规则，每个天赋只带一组修正项（`mods`），各系统的公式从同一处汇总取值。修正项共四十余种：

| 修正项 | 作用 | 单位 |
|---|---|---|
| 修炼速度 | 闭关所得修为 | % |
| 气血上限 / 灵力上限 | 此小阶段的基础值上加成 | % |
| 攻击 | 斗法中的攻击加成 | 点 |
| 减伤 | 受到的伤害减少 | % |
| 金、木、水、火、土系神通 / 神通威力 | 同属性神通伤害 / 全部神通伤害 | % |
| 寿元 | 寿命上限 | 年 |
| 单次闭关上限 | 一次闭关最长多久 | % |
| 闭关不倦 | 连续闭关多久才开始心神疲惫 | % |
| 历练感悟 | 斗法、委托等所得的历练 | % |
| 心境增长 | 各种来源所得的心境 | % |
| 境界所需心境 | 每个小阶段要求的心境 | % |
| 突破成功率 | 大境界突破的把握 | 点 |
| 丹药药效 | 丹药的效果 | % |
| 丹毒积累 | 增修为的丹药留下的丹毒 | % |
| 炼丹成功率 | 开炉的成丹把握（上品几率得一半） | % |
| 筑基品质提升几率 | 根基升一级的机会 | % |
| 抵御心魔 | 心魔不来的几率 | % |
| 机缘几率 | 各种机缘的几率 | % |
| 参悟耗时 | 参悟玉简的日数 | % |
| 采集收获 | 采集所得的株数 | % |
| 卖价 / 买价 | 交易价格 | % |
| 好感增长 | 交谈、赠礼等所得的好感 | % |
| 行路耗时 | 赶路的日数 | % |
| 途中遇险 | 途中遭遇的几率 | % |
| 养伤耗时 | 静养与内伤的日数 | % |
| 初始灵石 | 开局多带的灵石 | 点 |
| 斗法每回合多抽灵气 / 开局多抽灵气 / 灵气上限 | 斗法的灵气 | 颗 |
| 某属灵气更易抽到 | 加到该属的抽取权重上 | 点 |
| 神识 | 神识的数值 | 点 |

天赋的数值已经按等级放大好写在配置里：同一类加成，白色的「勤勉」修炼 +5%，绿色的「专注」+15%，蓝色的「一心向道」+36%，紫色的「修行奇才」+84%，橙色的「先天道体」+150%（另有突破 +50），红色的「仙人转世」+400%。代价不随等级放大。

### 2.3.2 分组

同一主题的系列天赋每人至多一个。天赋共分 28 组左右：体魄、悟性、五行亲和（金木水火土各一组）、出身、性情、心境、寿元、气运、丹道、剑道等。比如「铁骨」不会和「体弱多病」同时出现；一个人不会同时有「金灵亲和」与「锐金之体」。缺陷也挂在这些组里，所以缺陷不会与同组的天赋相冲。

### 2.3.3 出生表：大多数人平平无奇

出生表（`tables`）决定一个人生来有几个天赋、每个天赋是什么等级：

| 出生表 | 0 个 | 1 个 | 2 个 | 3 个 | 等级权重 | 缺陷几率 |
|---|---|---|---|---|---|---|
| 青云山一带的人物 | 50% | 35% | 12% | 3% | 白 920、绿 75、蓝 5 | 20% |
| 主角 | 30% | 40% | 22% | 8% | 白 860、绿 100、蓝 30、紫 6、橙 1、红 0.2 | 20% |
| 其他地域（留给中后期） | 45% | 35% | 15% | 5% | 白 800、绿 150、蓝 45、紫 5、橙 0.3 | 20% |

换成直观的说法：

| | 没有天赋 | 最高只有白色 | 有绿色（小天才） | 有蓝色（顶尖） | 紫色及以上 |
|---|---|---|---|---|---|
| 青云山一带的人物 | 约一半 | 多数 | 约二十人里一个 | 千人里几个 | 不会出生 |
| 主角 | 约三成 | 多数 | 约一成 | 约 3% | 极少：每次感应紫约 0.7%，橙约 0.1%，红约万分之二 |

前期只有主角可能生来带紫、橙、红天赋。中后期的其他地域里，人物也几乎不会有橙色，红色除主角外全世界都没有。

### 2.3.4 高阶天赋的专属内容

- **橙色天赋**各有一件专属奇遇：到某地时触发一次，送修为、心境、玉简、丹药或灵石。例如「气运之子」在青石镇街角被醉汉塞了一包破障丹与灵石；「剑骨」在古修洞府里让一柄锈剑铮然长鸣，剑身里藏着玉简。
- **红色天赋**各有一段两三步的专属剧情，由关键人物交代。例如「仙人转世」由老艄公认出前世故人，并指出灵眼所在；「混沌灵体」被顾长庚一把扣住脉门认出，筑基后亲自护持淬体。

这些内容在第九章逐一列出。因为高阶天赋极少，大多数玩家一辈子也见不到。

### 2.3.5 看别人的天赋

自己的天赋始终可见。别人的天赋要满足下面任一条件才看得出，否则资料卡上写「天赋 · 看不透（相熟之后，或神识高过此人，方能看出）」：

- 与其**相熟**（好感 40）；
- 自己的**神识**高过这名生成人物。

关键人物的天赋是手写的，只对相熟的人显露。

## 2.4 资质

资质不再只看灵根。灵根分加上每个天赋的等级分（缺陷 −2），按总分分为五档：

| 资质 | 分数 | 筑基成功率底数 | 生成人物能否筑基 |
|---|---|---|---|
| 下等 | 4 以下 | 25% | 10% |
| 中等 | 4–7 | 35% | 25% |
| 上等 | 8–11 | 45% | 40% |
| 绝佳 | 12–15 | 55% | 55% |
| 天纵 | 16 以上 | 65% | 70% |

三灵根（5 分）没有天赋的人是中等。双灵根（8 分）是上等。天灵根（12 分）是绝佳。一个三灵根的人带一个蓝色天赋（5 + 6 = 11）是上等；带一个紫色天赋（15）是绝佳。伪灵根（1 分）带两个白色天赋（3 分）也只有下等。

资质的作用：

- 决定**筑基成功率的底数**（见第三章）。结丹、结婴、化神在这个底数上再减去「金丹之难」「元婴之难」「化神之难」。
- 对生成人物，决定他们这一生**能否筑基**的几率（见第八章）。

## 2.5 开局的状态

- 年岁 16，炼气初期，修为 0。
- 气血上限 90，灵力上限 30，攻击加成 0，神识 10（加天赋修正）。
- 灵石 30（加天赋「初始灵石」）。
- 心境 0，历练 0。
- 宗门身份：青云剑宗外门弟子。
- 传承：散修三门神通——御剑诀、离火术、回春诀。
- 地点：青云山。

## 2.6 强制入门「初入山门」

新旅程由外门执事弟子许清和领着走一遍，约十几分钟。这是剧情 `intro`，有六个步骤：

1. **闭关一个月**。许清和领你进青云山：「我姓许，往后外门的杂事找我便是。修行先修根基——静室就在这里，你先闭关一个月，感受灵气入体。」出关时他在门外候着，讲一次闭关的上限与心境的要紧，让你去演武坪切磋。
2. **演武坪切磋**，胜负不论。许清和拍拍你的肩：「斗法能攒历练、磨心境。往后修为卡在瓶颈，就出去多走动走动。」
3. **去松风岭采三株灵草，再与阿芷说说话**。许清和教你点左上角的「舆图」，在图上选松风岭沿路启程，并提到岭上有位采药姑娘叫阿芷。
4. **回青云山交草**。许清和收下灵草，数出 30 灵石与两枚回气丹给你：「灵草在云溪坊市的药铺能换钱，丹药也在那里买。去坊市走一趟，认认门路。」
5. **去云溪坊市做一笔买卖**，在药铺或丹铺都行。药铺掌柜沈墨说往后有灵草只管拿来。
6. **回禀**。许清和：「入门的事就这些了。执事堂的委托、传功堂的传承、茶馆渡口的消息，往后都由你自己拿主意。」得一道传音符、一枚破障丹、心境 +3，记为一生大事。

入门期间的限制：

- 只能前往当前步骤指定的地点，舆图上说明原因；
- 第一次闭关固定一个月，其余步骤不能闭关；
- 路上不遇妖兽；
- 执事堂与传功堂在入门结束后才开放（场景条件 `requires_flag: intro_done`）；
- 右上角的目标固定写着当前步骤，每一步开始与结束时，师兄的话以整屏讲述。

**跳过入门**：在本机完整走完过一次入门之后，新旅程的标题界面多出「跳过入门指引」。跳过时入门记为已完成，宗门的后续剧情照常开始。是否走完过记在玩家自己的 `user://guide.cfg`（`intro_finished`），不进存档。

入门结束后，三段剧情会自动接上：许清和的「师门差事」、顾长庚的「传功之问」，以及（如果阿芷的好感够）阿芷的心事。

看过的卡记在**存档**里（`player.taught`），所以每段新旅程会重新教一遍；旧存档迁移时，原有的 11 张提示记为已看过，新增的卡照常出现。设置里可以关闭教学，也可以「重新显示本段旅程的教学」。门派试演（`preview_sects.cmd`）不显示教学。

## 2.8 当前目标

游戏是自由行动的沙盒，没有必须完成的主线。右上角始终写着一条「目标 · ……」，悬停可看全文；点「任务」卷轴的「当前目标」页能看到最多三条。它们只是眼下可以努力的方向，不是任务，按重要程度排列：

| 目标 | 何时出现 | 内容 |
|---|---|---|

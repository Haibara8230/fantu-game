# 第七章 宗门

> 历史快照：本章保留 2026-10-14 版本的说明与数值，未逐项同步后续系统。旧价格、突破丹、宗门门槛、剧情及界面说明不能作为当前操作依据；现行入口见 [当前状态](../CURRENT_STATUS.md)、[游戏介绍](../GAME_INTRO.md) 和 [设计基线](../DESIGN_BASELINE.md)。本次仅整理状态，不把旧表宣称为重新验收的现行数值。

玩家是青云剑宗的弟子。「宗门」原来只代表所修的传承，后来参照《觅长生》的宗门，加上了身份、贡献、月俸、兑换、捐献与职司。规则在 `scripts/core/sect.gd`，数值在 `data/sect.json`，「人物 · 宗门」页在 `scripts/ui/sect_view.gd`。宗门事务都在青云山**执事堂**的「宗门事务」里办理。

---

## 7.1 青云剑宗

青云剑宗在青云山，外门弟子的静室、执事堂、演武坪、传功堂都在山上，内门弟子在山中有自己的洞府。宗门的镇派传承是青云剑诀：御剑诀、三才剑阵、断月斩，御剑蓄势，连斩收锋，以剑阵与月弧破敌。守御时身边环绕飞剑。

宗门里的人：

- **许清和**，外门执事弟子，炼气后期，23 岁。新入门的同门大多由他领着认路，说话爽快，记性极好，谁欠药堂几株草都记得清清楚楚。主持外门精英的晋升。
- **顾长庚**，传功长老，筑基圆满，168 岁。掌管传功堂，五套传承的玉简都经过他的手；话不多，看人却准。主持内门弟子、真传弟子与长老的晋升。
- 生成的**青云外门弟子**：常住青云山，是演武坪切磋与外门小比的对手。

## 7.2 五级身份

| 身份 | 晋升条件 | 月俸 | 在宗门闭关 | 主持 | 新开放的事 |
|---|---|---|---|---|---|
| 外门弟子 | 开局 | 3 灵石 | +0% | — | 基础兑换 |
| 外门精英 | 累计贡献 120，炼气中期 | 8 灵石 | +5% | 许清和 | 兑换筑基丹、筑基丹方、紫铜丹炉 |
| 内门弟子 | 累计贡献 400，筑基 | 20 灵石 | +10% | 顾长庚 | 洞府与灵田；玄阶玉简、玄铁丹炉、玄阶料、凝元丹；职司；「内门之路」 |
| 真传弟子 | 累计贡献 1200，金丹 | 50 灵石 | +15% | 顾长庚 | 地阶玉简、化婴丹、化神丹 |
| 长老 | 累计贡献 3000，元婴 | 150 灵石 | +20% | 顾长庚 | 「长老之位」剧情完结 |

在执事堂点「申请晋升」，由主持人授予，记为一生大事，相识会道贺。晋升时的话：

- **外门精英**：许清和把一枚青玉腰牌递到你手里：「外门精英。往后每月多领几块灵石，宗门的筑基丹也能拿贡献来换了——一年里能换到的人，外门不过十来个。」
- **内门弟子**：顾长庚亲手为你系上内门的白玉腰牌：「入了内门，你便有了自己的静室，灵气比外门浓上一成。宗门的大事，往后也要算你一份。」
- **真传弟子**：顾长庚把一枚紫玉令牌按进你掌心：「结了丹，便是本门真传。宗门的典籍、丹房与灵脉，往后都向你敞开；宗门有事，你也得站在前头。」
- **长老**：顾长庚亲手把长老的青玉冠戴到你头上，退后一步，郑重一揖：「青云山的长老。往后这座山，有你一份担子。」

道贺：许清和「听说你晋升了？往后执事堂的差事，给你挑好的」；顾长庚「晋升的事老夫听说了。身份是宗门给的，路是自己走的」。

累计贡献过半时，「当前目标」会提示晋升的条件；条件齐了提示回执事堂申请。

## 7.3 贡献

贡献分两本账：

- **贡献**（`player.contribution`）：可花的余额，兑换时扣除。
- **累计贡献**（`player.merit`）：只增不减，用来晋升。

### 7.3.1 贡献的来路

| 来路 | 贡献 |
|---|---|
| 执事堂委托：收购灵草 | 每株 3 |
| 执事堂委托：清剿妖狼 | 每头 10 |
| 执事堂委托：巡视 | 25 |
| 执事堂委托：诛除魔修（金丹） | 每名 60 |
| 执事堂委托：斩千年蛟（元婴） | 200 |
| 许清和的师门差事 | 15、20、10 |
| 「内门之路」三次召见 | 40、40、60 |
| 「真传之责」诛除魔修 | 120 |
| 外门小比 | 每胜一轮 10，夺魁另 80 |
| 五宗论道 | 每胜一轮 40，夺魁另 300 |
| 斩赤鳞妖蟒 | 100 |
| 斩魔潮魔将 | 500 |
| 捐献 | 见 7.5 |

坊市告示的委托不记贡献。职司「巡山执事」让委托所得贡献多五成。执事堂委托每 60 日 3 张，捐献与兑换都有期限上限，刷不出无限的贡献。

## 7.4 月俸

按月累积，回执事堂「领取月俸」，至多积 12 个月。闭关十年回来，只能领到一年的。

---

## 7.5 捐献

灵草与材料可以捐给宗门，按市价的一半折贡献，每月至多 40。按钮写作「捐献某某×N（贡献 +M）」。

## 7.7 职司

内门弟子起，可在执事堂领一项职司，一年一换：

| 职司 | 说明 | 效果 |
|---|---|---|
| 丹房执事 | 管着宗门丹房 | 炼丹成功率 +10 |
| 巡山执事 | 领着巡山与委托 | 交付委托所得贡献多五成 |
| 传功执事 | 协理传功堂 | 参悟功法耗时少两成 |

宗门页写着「职司 · 某某」或「职司 · 未任」，三个按钮各写说明；正担着的那一个以金色标出。换职的限制：「职司一年一换，N 后可改。」领职时编年史记「你在执事堂领了某某的差事」。存档：`player.duty`、`player.duty_day` 可选。

## 7.8 宗门页

「人物 · 宗门」页写着：

- 宗门名与传承；
- 身份、贡献余额、累计贡献、下一级的条件；
- 月俸与可领的数目；
- 在宗门闭关的加成；
- 职司；
- 宗门兑换的全部货品与本期余量；
- 可捐献之物。

事务须在执事堂办理；不在青云山时按钮变灰，说明「须到青云山执事堂」。

---

## 7.9 宗门与玩家的一生

宗门在玩家一生的各个阶段召唤他：

| 阶段 | 宗门的召唤 |
|---|---|
| 入门 | 许清和领着走「初入山门」 |
| 炼气 | 「师门差事」三次传音派活；「传功之问」拜见、研习、筑基指点；外门小比 |
| 筑基 | 宗门请柬（特殊拍卖）；「传功之问」指点去寻古修洞府；晋升内门后的「内门之路」三次召见：巡山拿劫修、灵潮吐纳、内门考校；五宗论道 |
| 金丹 | 「真传之责」：诛除魔修，听一桩旧事；执事堂的魔修委托；大劫守山 |
| 元婴 | 「长老之位」：受冠；执事堂的千年蛟委托 |

**大劫**是宗门最大的一件事：历元 300 年三月，天魔破界，魔潮涌向青云山，护山大阵升起，宗门传令「金丹以上弟子，到山门守山」。青云山多出「山门」场景，魔潮魔将在阵外叫阵（650 / 36–46）。斩之：魔潮群龙无首，攻势一下子散了；1000 灵石、3000 修为、500 贡献、一件天阶宝物；顾长庚「山门前那一战，老夫在阵里看着。青云能有今日，是你的功劳」，何三更「《山门斩魔将》！这回书老夫说到老也说不完！」。302 年三月魔潮退去：魔将已斩则「青云山保住了，山门前立起一块新碑」，心境 +10；未斩则「青云山已是满目疮痍：外门的屋舍塌了大半，许多熟悉的面孔再也见不到了」。

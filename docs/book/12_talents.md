# 附录一 天赋与缺陷全表

> 新角色现用 [2026-10-28 开局重做](../OPENING_REWORK_20261028.md)：30 项独立天赋、多选组合、逐项价格和独立悟性。下文的大额高阶天赋及随机出生规则用于历史存档／NPC，不代表当前开局可选项。

> 历史快照：本章保留 2026-10-14 版本的说明与数值，未逐项同步后续系统。旧价格、突破丹、宗门门槛、剧情及界面说明不能作为当前操作依据；现行入口见 [当前状态](../CURRENT_STATUS.md)、[游戏介绍](../GAME_INTRO.md) 和 [设计基线](../DESIGN_BASELINE.md)。本次仅整理状态，不把旧表宣称为重新验收的现行数值。

本表由 `data/talents.json` 直接生成，列出全部天赋与缺陷的名称、描述与效果。效果的写法与游戏里鼠标悬停时一样：百分数是比例修正，「点」是突破把握的点数，「年」是寿元，没有单位的是加减的数值或颗数。天赋的规则见第二章 2.3。

「分组」一栏是天赋所属的系列：同一分组的天赋（以及挂在同组的缺陷）每人至多一个。标「机缘所赐」的天赋生来不会有，只能由机缘赐下。分组为「—」的是不成系列的零散天赋，彼此之间不互斥。

共有 27 个分组：体魄、根骨、人缘、沉稳、道心、识药、寿数、福缘、记性、勇力、吉凶、出身、修行勤惰、药体、愈伤、脚程、气海、闭关、性情、商道、家资、悟性，以及金木水火土五行亲和各一组。出身（37 种）与性情（23 种）两组最大；一个系列从白到紫逐级加强，往往配着一个同组的缺陷，比如修行勤惰一组是勤勉（白）、专注（绿）、一心向道（蓝）、修行奇才（紫）与缺陷懒散。

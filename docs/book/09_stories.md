# 第九章 剧情、事件与探索

> 历史快照：本章保留 2026-10-14 版本的说明与数值，未逐项同步后续系统。旧价格、突破丹、宗门门槛、剧情及界面说明不能作为当前操作依据；现行入口见 [当前状态](../CURRENT_STATUS.md)、[游戏介绍](../GAME_INTRO.md) 和 [设计基线](../DESIGN_BASELINE.md)。本次仅整理状态，不把旧表宣称为重新验收的现行数值。

游戏没有主线，但有许多故事。它们分三种：**剧情**（一位交代之人、几个按顺序推进的步骤）、**事件**（到某地或到某日发生的一件事，可能要抉择）、**探索**（洞府与古境里一间一间的石室）。本章把它们全部列出。

---

## 9.1 剧情系统怎样运转

剧情定义在 `data/storylines.json`，规则在 `scripts/core/storylines.gd`，进度存在 `world.storylines`。

- 一段剧情有一位**交代之人**（`giver`）和若干**步骤**，按顺序推进。
- 剧情由效果 `start_story` 开始（比如问沈墨赤鳞果的来历），或在 `begin_if` 成立时自行开始（比如入门结束、结丹）。
- 步骤在 `requires` 满足时开始，开始时讲出 `say`（`letter: true` 时以传音送达）。从此刻起计数 `deeds`：闭关天数、斗法、交易、采集、委托、相助、击败某种敌人等。
- 步骤的完成方式：
  - `done` 条件与 `deeds` 都满足；
  - 或等候 `wait_days` 日（等候期满送来的传音会打断闭关）；
  - 或人物的某个交互带 `story_advance` 效果（如把灵草交给师兄）；
  - `auto` 步骤开始即完成。
- 完成时施加 `effects`（灵石、物品、心境、好感、贡献、玉简、标记、传音符……），讲出 `after`。
- 剧情或步骤的 `close_if` 成立时剧情作罢，讲出 `closed`；步骤的 `skip_if` 在开始前成立时悄悄跳过。
- 「任务 · 剧情」页列出进行中与已完结的剧情，写着眼下一步该去哪、做什么（`goal` 与 `place`）。标 `major` 的步骤记为一生大事。

## 9.2 宗门的剧情

### 9.2.1 初入山门（许清和）

见第二章 2.6。六步：闭关一月 → 演武坪切磋 → 松风岭采三株灵草并与阿芷说话 → 回山交草（30 灵石、两枚回气丹）→ 坊市做一笔买卖 → 回禀（传音符、破障丹、心境 +3，大事）。

### 9.2.2 师门差事（许清和）

- **开始**：入门结束。**作罢**：筑基——「你已筑基，外门的差事不再派到你头上。」
1. 等 90 日。
2. **凝露草**（传音）：「药堂又缺凝露草了。你若得空，采三株送到执事堂，药堂有赏。」交上三株凝露草：许清和塞给你一枚破障丹：「药堂的谢礼。修为卡住时服下，比闷头闭关管用。」好感 +10、心境 +2、贡献 15。
3. 等 180 日。
4. **斩狼**（传音）：「落霞谷谷口的妖狼伤了两个采药的外门弟子。你若有余力，去谷口斩一头，替他们出这口气。」斩一头妖狼：妖狼伏诛，你割下狼牙作凭证。
5. **回禀**：许清和接过狼牙，喜道：「好！这是执事堂的赏，那两个师弟也托我谢你。」60 灵石、好感 +10、心境 +3、贡献 20。
6. 等 360 日。
7. **小比提醒**（传音，自动完成）：「外门里都在议论下一回小比。平日多去演武坪切磋，报名时别错过了——头名能得一卷好功法。」心境 +1、贡献 10。

### 9.2.3 传功之问（顾长庚）

- **开始**：入门结束。
1. **拜见**：许清和又叮嘱一句：传功堂的顾长庚长老管着宗门传承，入门弟子都该去拜见。到传功堂与他交谈：顾长庚抚须道：「散修那三门神通够你防身，却走不远。本门青云剑诀，御剑诀、三才剑阵、断月斩，攻守都有章法。到传功堂静心研习一月，便是我青云的剑修了。至于他派的神通，各家秘不外传，除非得其玉简，或有人肯教你。」
2. **研习**：在传功堂研习本门青云剑诀（约一个月）。顾长庚看了你演练的几式，点头道：「有模有样。往后修到圆满，记得来见我。」他留给你一道传音符。心境 +3。
3. **筑基之道**（传音；炼气圆满时开始，已筑基则跳过）：「听说你已修至炼气圆满。筑基一关，不只是修为与丹药——来传功堂，老夫有几句话交代。」请教筑基之道：顾长庚：「筑基丹不只丹铺有卖，云溪夜市、坊间拍卖、行脚的药贩都可能遇上。心境跟不上，闭不了长关，筑基之后更是如此。这枚凝气丹你拿去。突破那日，来传功堂说一声，老夫替你护法。」凝气丹一枚、心境 +4。**从此顾长庚愿为你护法。**
4. **古修洞府**（传音；筑基后开始，已找到洞府则跳过）：「恭喜筑基。外门的规矩管不到你了。落霞谷深处传说有座古修洞府，以你如今的神识，该去看看了。」找到洞府：心境 +3。

### 9.2.4 内门之路（顾长庚）

- **开始**：晋升内门弟子。召见彼此相隔 1 年、2 年、3 年。
1. 等 360 日。
2. **巡山**（传音）：「筑基弟子按例轮流巡山。北边山道近来又有劫修出没，这一趟轮到你了。」击败蒙面劫修：劫修伏法，山道又清静了一阵。宗门记下你一功，赏灵石 150，心境 +4，好感 +10，贡献 40。
3. 等 720 日。
4. **灵潮**（传音）：「落霞谷灵泉每隔几年灵潮涌动，筑基修士在泉边吐纳一回，胜过闭关半年。这一回的灵潮就在眼下，莫要错过。」到落霞谷：灵泉上白雾翻涌，你盘坐泉边吐纳了一整夜，周身经脉被灵潮冲刷得通透。修为 +360、心境 +3、贡献 40。
5. 等 1080 日。
6. **内门考校**（传音）：「内门考校将开。筑基弟子都要在演武坪过一过手，老夫亲自看。」在演武坪斗法一场：顾长庚看完你的斗法，只说了两个字：「尚可。」转身却让人送来一枚玉简——是他年轻时用过的功法。玄阶玉简、心境 +5、贡献 60，大事。

### 9.2.5 真传之责（顾长庚）

- **开始**：结丹。
1. **召见**（传音）：「结丹了？来传功堂一趟。真传弟子有真传弟子的担子。」到青云山：顾长庚：「结丹之后，你便不是只为自己修行了。深谷灵泉那边魔修猖獗，掳人炼魂，执事堂的告示你也看见了。去，诛了它们。」心境 +4。
2. **诛魔**：在深谷灵泉诛除两名魔修。两名魔修伏诛，灵泉一带的采药人又敢进谷了。顾长庚传音：「做得干净。」300 灵石、120 贡献、心境 +6、好感 +10。
3. 等 720 日。
4. **旧事**（传音）：「有一桩旧事，老夫想了许多年，也该让你知道了。回传功堂来。」到青云山：顾长庚取出一枚边角残缺的玉简：「沉霞古境百年后才会再开。这是老夫当年从里面带出来的，可惜残了。你拿去参一参，或许用得上。」地阶玉简、心境 +6，大事。——为沉霞古境埋下引子。

### 9.2.6 长老之位（顾长庚）

- **开始**：结婴。
1. **召见**（传音）：「元婴……青云山已经两百年没出过元婴了。回来一趟，老夫有话同你说。」到青云山：顾长庚：「宗门的长老位子空了一个，空了很多年。你若愿意担，攒够贡献，便来执事堂受冠。」心境 +6。
2. **受冠**：晋升长老（累计贡献 3000）。受冠那天，青云山的钟响了九下。顾长庚站在台下，像是一下老了许多，又像是一下轻松了许多。「往后，这座山交给你们了。」心境 +10、好感 +20，大事。

## 9.3 故人的剧情

### 9.3.1 赤鳞果（沈墨）

- **开始**：与阿芷说过话、沈墨好感 15、妖蟒未除时，问沈墨「赤鳞果的来历」：沈墨放下算盘：「赤鳞果？那东西长在妖蟒窝边，妖蟒吃了它，鳞甲硬得像铁。阿芷她爹就是贪那几颗果子……你若真想对付那孽畜，凑齐三株凝露草、两株赤炎花来，我替你熬一剂破鳞散。」
1. **熬药**：交三株凝露草、两株赤炎花。沈墨把药材投进药碾：「凝露草性寒，赤炎花引药入血，熬成破鳞散。斗妖蟒前服下，它那身鳞甲便硬不起来。」得破鳞散。（妖蟒已除则作罢：「妖蟒已除，沈墨的破鳞散用不上了。他笑说这样最好。」）
2. **斩蟒**：服下破鳞散，筑基后往深谷灵泉斩除妖蟒（妖蟒气血减三成）。沈墨听说妖蟒伏诛，关了半日铺子，请你喝了一壶好酒：「阿芷她爹那笔账，算是清了。」80 灵石、好感 +20、心境 +3。（若是宗门长老代为除蟒：「宗门长老出手斩了妖蟒，沈墨把那包没用上的破鳞散收回药柜，说留着也好。」）

### 9.3.2 冰河剑痕（老艄公）

- **开始**：老艄公好感 10，问起那位劈冰的剑修：老艄公眯起眼：「那年冬天河面冻得结实，一位剑修踏冰而过，随手一剑，冰面裂开三丈。后来我撑船经过那里，总觉得河底有东西发冷……你要是哪天神识够用了，替老汉下去瞧瞧。」
1. **探河底**：神识到 30（筑基便有）之后，请老艄公撑船。河底的青石上留着一道剑痕，残存的剑意凛冽如冰。你以神识拓下那一缕剑意，化作一枚玉简。老艄公撑着篙嘿嘿直笑：「我就说那一剑不寻常。」玄阶玉简、心境 +5、好感 +10，大事。

### 9.3.3 货郎遇劫（钱货郎）

- **开始**：钱货郎好感 6，问他为何愁眉不展：「前些日子叫一个蒙面劫修截了道，半副货担的丹药全没了。那人常在松风岭、落霞谷和白鹭渡一带晃悠……道友若能把货担夺回来，小老儿必有重谢。」
1. **夺货担**：击败蒙面劫修。劫修败走，丢下一副货担，里头的丹瓶一个没少。
2. **还货担**：钱货郎抱着货担直搓手：「恩公！往后从我这儿拿筑基丹，只收五十五灵石。」他留给你一道传音符。好感 +20、心境 +3。

### 9.3.4 寒舟之约（柳寒舟）

- **开始**：救过柳寒舟、找到古修洞府、洞府尚未易主。
1. **劝离**（传音）：「听说你寻到了落霞谷深处的洞府。占着那里的石寒，原是我的师兄。他走岔了路，却不是恶人……若能劝他离开，莫伤他性命。你只说『寒舟还记得松风岭的那壶酒』，他便明白。」到古修洞府转告石寒：石寒沉默良久，收剑入鞘：「告诉寒舟，那壶酒我还欠着。」他背起行囊，头也不回地出了洞府。洞府易主，不必斗法。（若直接斗法则作罢：柳寒舟传音来，只说了一句：「师兄的事，我听说了。不怪你。」）
2. 等 30 日。
3. **谢礼**（传音，自动完成）：「师兄传了信来，说要去北边重新开始。这份情我记下了——托人捎去五十灵石与一枚凝气丹，聊表心意。」50 灵石、凝气丹、好感 +20、心境 +4。

## 9.5 事件系统怎样运转

事件定义在 `data/events.json`，规则在 `scripts/core/events.gd`。

| 字段 | 含义 |
|---|---|
| `trigger` | `location`：玩家在该地点行动后检查；`date`：到日期即发生，与玩家位置无关；`route`：途中遭遇；`manual`：由规则直接触发（心魔、顿悟、灵眼、残魂） |
| `window` / `periodic` / `repeat` | 固定时间窗口（年、月、日）/ 周期（每 N 年某月某几日）/ 冷却天数，三选一 |
| `conditions` | 境界、世界标记、物品、灵石灵草、相识与交情、其他事件状态、天赋、神识；可用 `all` / `any` / `not` 组合 |
| `effects` | 增减资源与物品、设置标记、结识人物、改变交情、开始斗法、开场拍卖、重置古境 |
| `choices` | 抉择事件的选项；每个选项可有自己的条件与效果 |
| `remind` | 窗口开启时提醒知情的玩家，并打断闭关 |
| `expire` | 窗口结束仍未参与时，给知情的玩家留下后续传闻 |
| `priority` / `group` | 同时满足时的先后顺序 / 互斥组，同组每次只触发一个 |
| `key` | 关键事件，必须提供至少两条入场途径 |

- 状态：未发现与可触发由条件推导；完成、过期写入存档；进行中的抉择保存在 `pending_event`，期间不能做其他事。
- 抉择事件在整屏的事件画面上呈现：插图、标题、正文（按文字速度逐字显示）、选项按钮；条件不足的选项变灰。经历有抉择的事件得历练 15、心境 2。
- 内容静态检查在加载时运行：未知地点、标记、物品、人物或事件，时间窗口颠倒，没有无条件选项（玩家会被卡住），关键事件只有一条途径，提醒或过期用在周期事件上，等等。

## 9.7 洞府探索

参照《觅长生》的洞府探索。规则在 `scripts/core/caves.gd`，石室在 `data/caves.json`，石室图在 `scripts/ui/cave_view.gd`。

### 9.7.1 怎样探索

- 点开探索的场景是一张石室图：已探的石室亮着，与它们相连的门洞可以「探入」，其余隐在黑暗里。
- 进入一间与已探石室相连的新石室耗时（洞府深处每间 2 日，沉霞古境每间 3 日）。探过的石室一直亮着，不必再走一遍；离开洞府再回来，进度还在。
- **机关**：神识够就识破绕开；不够则中机关受伤（不会致死）。
- **宝物**：进门即取。同一世界取到的东西相同——按世界种子从几种里挑一种。
- **暗格**：神识够才看得见，破开禁制耗灵力。
- **门上的禁制**：神识不够进不去。
- **守卫**：进入守卫所在的石室即开始斗法（事件引起的斗法，胜后只整顿 1 日）。打不倒它，这间的宝物拿不到、后面的石室进不去。落败或撤离后可再战。
- 存档：`world.caves` 可选，记已探的石室、已取的东西与两样机缘有没有；旧存档读进来是一座没探过的洞府。

# 第十章 界面与操作

界面参照《觅长生》的分屏式布局：每个地点是一整屏的场景画，事情在场景上弹出的卷轴里办；斗法、事件、突破、结局各占一整屏。画布是 1280×720，按 1.25 / 1.5 / 2 倍整体缩放到 1600×900、1920×1080、2560×1440，排版不变。只做 16:9：目标是 1080P 与 2K 屏幕的全屏或缩小的窗口。

界面代码在 `scripts/ui/`，`main.gd` 是总调度，各页面各占一个脚本。界面只读规则的结果来画，不改规则的状态；规则改了什么，界面在 `changed` 信号上重画。

---

## 10.1 画面的风格

- 二维手绘：清晰的描边、平涂的颜色、克制的阴影，人物不走写实路线。
- 底色是深青（`#0a171a` 一类），边框是青灰（`#41615e`），标题与强调用金色，正文是米白的墨色，次要信息是灰绿。
- 卷轴与纸条用竹简、宣纸的质感：卷轴两侧有竹框，正文离竹框留出边距（左右 52、上 14、下 24），不贴在竹子上。
- 品级颜色：白、绿、蓝、紫、橙、红，物品、功法、法宝、天赋同用一套。
- 禁用的按钮文字仍保持足够的对比度，读得清楚。

## 10.2 常驻信息（HUD）

在地点画面与舆图上一直显示：

### 10.2.1 左上：我是谁

- 一枚方印，印着道号的第一个字；
- 道号与境界（「炼气中期」）；
- 三条细进度条：气血、灵力、修为（「气血 96 / 100」）；
- 一排按钮：**人物、行囊、神通、舆图、编年史**。在舆图上「舆图」变成「此地」。

在舆图上，这块面板挪到左下角（区域地图把那里空着）。

### 10.2.2 右上：何时何地，该做什么

- 日期（金色，「历元 6 年 三月初一」）与所在地；
- 「**任务**」按钮，有未读传音时写作「任务 · 传音 3」；
- 一行当前目标「目标 · 冲开瓶颈」，悬停看全文；
- 行程未竟时：「行程未竟 · 落霞谷 · 约 3 日」与「继续赶路」按钮。

### 10.2.3 左下：最近的记载

最近两条编年史，浮在一层暗色底上，长了就向上长。舆图上不显示（它们都在「任务 · 消息」里）。

### 10.2.4 底部：提示条

刚发生的事以一条提示显示在底部，随文字长短向上长到至多六行，六秒后淡去；完整的内容留在「任务 · 消息」里。斗法时提示条挪到上方（操作盘占着底部），放在对手的意图面板之下，不遮挡它。

## 10.3 地点画面

- 整屏是此地的场景画，顶部居中是地名（大字金色）与副题（「山中无甲子，修行亦有时。」）。
- 各处场景是贴在各自建筑上的**竖排纸条**（静室、执事堂、演武坪……），点开才在中间弹出卷轴；卷轴里是场景的插图、描述与能做的事。关闭（或 Esc）后场景重新完整露出。
- **此地人物**在左边缘的抽屉里：竖排的「此地人物 N ▶」，点开是一列人名（带 ❗ 的有事相托），人多时折叠为「更多 · N 人」。点一个人也在卷轴里面对面：中央是立绘，两侧是交互选项（交谈、赠礼、切磋、请教、求传功法、相助、赴约切磋、送上某物、道侣、弟子、结拜，以及剧情选项，剧情选项以金框标出）。
- 右下角「离开 · 舆图」。

### 10.3.2 整屏演出

闭关、突破、炼丹时整屏演出：打坐聚气、冲关的金光或反噬、炉火开炉。点击可加快。

## 10.4 舆图

- 整屏的区域地图，七处地点画在各自的位置，路线连着它们，隐藏的地点（古修洞府）发现之前不显示。
- 主角的小人站在所在地。点一处地点，小窗里写着路线、日数与危险，「启程前往」。
- 赶路是演出：规则先走完，舆图再让小人沿实际走到的地方一步步走过去，并朝行进方向转身，日期随之走动。遭遇打断时停在打断处，回到舆图后可以继续。
- 金丹以后小人踏剑而飞。
- 结识的人标在他们此刻所在的地点上。
- 入门期间不能去的地点说明原因；封谷时落霞谷标为封锁。

| 页签 | 内容 |

| 宗门 | 身份、贡献、累计贡献、下一级、月俸、职司、兑换、捐献（第七章） |
| 神通 | 四个栏位与全部习得的神通，替换 |
| 功法 | 两个心法栏位与习得的心法，替换 |

| 相识 | 全部相识，「相识 · N 人」，按地点、好感排列；点开是人物志；「在舆图上查看」 |

## 10.6 任务卷轴

右上角「任务」打开卷轴，六个页签：

| 页签 | 内容 |
|---|---|
| 当前目标 | 最多三条，眼下可以努力的方向（第二章 2.8） |
| 剧情 | 进行中与已完结的剧情，写着眼下一步该去哪、做什么 |
| 委托 | 已接的委托：进度、期限、交付地点 |
| 传音 | 最上面是待回复的来往（对方在哪、期限到哪天，借钱在这里答复），然后是收到的传音 |
| 约定 | 临近的大事与约定：外门小比、特殊拍卖、妖蟒之期、相识约你的事 |
| 消息 | 最近 80 条记载（斗法中一招一式的不列），闭关、停留期间收到的告示与消息都能在这里翻到 |

## 10.7 闭关卷轴

在静室点「闭关修炼」或「突破境界」打开，两个页签：

- **修炼**：滑条选时长；每月修为及其来源；此番最长可闭多久；所选时长的预估（修为、会不会在途中触及瓶颈或上限、出关时的心神）；旁边列出近期的大事（妖蟒、拍卖、小比、封谷）。「开始闭关」。
- **突破**：要服几枚丹（上品先服）、用不用天材地宝、请谁护法；把握逐项列出，合计；心魔会不会来；「开始突破」。

## 10.9 编年史

- 新的在前，按年分组，每页 40 条，「较早」「较近」翻页。
- 标题写「编 年 史 · N 条」。按类别筛选：全部、大事、修炼、斗法、人物、剧情与传音、炼丹与灵田、行旅、交易与委托、奇遇与传闻。一类记载可属于多组（比如切磋既是斗法也是人物）。
- 编年史从开局就以结构化方式记录（事件 id、参数、日期），显示时再生成文字。重大经历终生保留，日常琐事只保留最近 100 条。
- 结局后可以翻看完整的一生。

## 10.11 设置

设置对话框分四页：

| 页 | 选项 |
|---|---|
| 声音 | 总音量、配乐、音效、环境声 |
| 画面 | 全屏；窗口 1280×720、1600×900、1920×1080、2560×1440 四档，默认 1600×900，超出屏幕的档位不可选 |
| 按键 | 保存、读取、四门神通、结束回合、守御可改键；「恢复默认按键」 |
| 游戏 | 文字速度（即时 / 快，每秒 60 字 / 中，30 / 慢，15，默认快）；自动存档；右上角当前目标；新手指引（关闭，或「重新显示本段旅程的教学」） |

- 全部写在玩家自己的 `user://settings.cfg`，不进存档；文件里的值不合法时退回默认。
- 界面上提到按键的文字（斗法按钮、新手指引、状态栏）跟随当前按键。
- 文字速度作用于事件文字、无抉择大事的插图卡片和对话框，同一场景重画时不再重打。

## 10.12 按键

| 动作 | 默认 |
|---|---|
| 保存 | F5 |
| 读取 | F9 |
| 第一至第四门神通 | 1、2、3、4 |
| 结束回合 | 空格 |
| 守御 | G |
| 关闭卷轴、对话框 | Esc |

改成已占用的键时两者互换。Esc、回车、Tab 与单独的修饰键（Shift、Ctrl、Alt、Win、CapsLock）保留给对话框，不能分配。之前存下的按键文件里守御仍在空格时，空格改给结束回合，守御改回 G。

## 10.13 存档与读档

- **自动存档**：每次有效行动后自动保存（可在设置里关闭）。
- **手动存档**：F5，或「系统 · 保存」。F9 读取。
- 自动和手动各保留两代，最新一代损坏时读取前一代。
- 「继续旅程」读取自动与手动存档中较新的一份（按文件时间）。
- 存档在玩家的用户目录 `%APPDATA%\Godot\app_userdata\凡途 · 修仙纪事\saves\`。
- 斗法、拍卖、抉择进行中都能存档，读档后接着进行。
- 存档目前第 15 版，所有旧版本的存档都能读入（第十一章）。

## 10.15 门派试演

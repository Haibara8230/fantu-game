# 《凡途 · 修仙纪事》游戏全书

本书完整描述《凡途 · 修仙纪事》这款游戏：它是什么、世界里有什么、玩家能做什么、每个系统怎样运转、数值从哪里来、界面怎样排布，以及程序如何组织。它写给三类读者：

- **玩家与试玩者**：想知道某件事怎么做、某个数值为什么是这样、错过了什么、还能走到哪里。
- **策划与美术**：想在已有的世界上添内容，需要知道已有的人物、地点、剧情、规则与它们之间的牵连。
- **程序**：想改规则或修问题，需要知道规则写在哪个脚本、数据写在哪个配置、存档怎样迁移、测试怎样跑。

本书以 2026-10-14 的版本为准（存档第 15 版，提交 `9bc225e` 之后）。书中的数值全部取自 `data/` 下的配置文件；配置一旦改动，以配置为准。规则的精确描述与改动记录见 `docs/DESIGN_BASELINE.md`，尚未完成的工作见 `docs/BACKLOG.md`，面向玩家的简短介绍见 `docs/GAME_INTRO.md`。

## 一句话介绍

一介凡身，问道长生。你是青云剑宗外门的一名新弟子，在一个按日流转、不会等你的修仙世界里，用几十年到几百年的岁月修炼、游历、结交、炼丹炼器、参与宗门与天下的大事，最后要么寿尽坐化，要么在第四百八十年踏上天河渡桥，白日飞升。

## 本书的约定

- **「历元」**是游戏内的纪年，玩家入门那一天是历元 1 年 1 月初一。每月 30 日，每年 12 个月，一年 360 日。
- **数值**写作「80 / 6–10」时，前者是气血，后者是每回合伤害的范围。「炼气中期」写作 `[0, 1]`（第 0 个大境界的第 1 个小阶段），这是配置文件里的写法。
- **品级颜色**：物品、功法、法宝、天赋共用一套颜色——白、绿、蓝、紫、橙、红。功法与法宝的五个品阶依次是凡品（白）、黄阶（绿）、玄阶（蓝）、地阶（紫）、天阶（橙）。
- 书中提到的脚本路径以仓库根目录为准，例如 `scripts/core/combat.gd`。
- 凡写「读档不变」的东西，意思是它由世界种子决定，不靠存读档就能刷出另一个结果。

# 界面改版：按界面切换（参照《觅长生》）

> 状态：第 1 步已完成（2026-10-12），其余按第 4 节继续。参考截图在 `PNG/`（只在本地，不进 git；`PNG/steam/` 是 Steam 官方截图，其余 16 张的来源见 `PNG/REFERENCE_INDEX.md`）；还缺的截图见第 5 节。确认后按第 4 节分步实施。

## 1. 为什么改

现在所有内容挤在一个窗口里：顶部一排按钮，左侧栏（状态、当前目标、委托、相识、约定、行程），中间面板，底部修行手记和状态栏。斗法、事件、突破只是中间面板换了内容，四周的框架一直都在，信息多而杂。

目标：像《觅长生》一样**按界面切换**。场景、大地图、战斗、突破、各种面板各占整屏；常驻信息压到最少，其余点开才看。

**原则**
- 照搬的是**结构**：界面怎么分、信息放在哪、怎么进出。截图里的美术（图标、边框、屋檐标签栏、书法字、装饰）不能拿来用，外观全部用本作的二维手绘风格重新做。
- 规则不动。改版只涉及界面与演出；存档、玩法、数据格式不因改版而变。
- 每一步做完都能玩，测试照常全部通过。

## 2. 《觅长生》的界面结构（据 `PNG/` 的截图）

### 2.1 常驻信息：只有左上和右上两小块
- **左上**：圆形头像；道号；生命条（红）；修为条（蓝）。下面一排 4 个圆形图标按钮，打开功法、物品、任务一类面板。（`01`、`03`、`07`）
- **右上**：日期（`510年1月15日`）；当前所在地（带小图标）；一个卷轴形「任务」按钮。
- 除此之外屏幕上**没有常驻的侧栏或日志**，整屏留给场景本身。
- 特殊状态在顶部正中挂一小块（洞府里的「雷劫 剩余 48 年」，`12`）。

### 2.2 场景界面（城镇、宗门、洞府）
- 整屏一张**俯视角手绘场景图**，各处建筑上挂**竖排纸条标签**（藏经阁、炼丹房、客栈、灵药堂、传送阵……），点标签进入。（`01`、`07`）
- 右下角圆形「**离开**」按钮；有传送阵的地方在它上面叠「传送阵」。
- **洞府**的右下角是一列竖排圆形功能按钮：神游、装扮、**闭关**、离开。闭关从这里进。（`12`）

### 2.3 大地图（行路）
- 整屏手绘地图；地名用竖排纸条标在节点旁；一个 Q 版小人站在路线上，沿路线移动。（`03`）
- 大地图上**直接弹对话**：底部一条横向对话框，左侧半身立绘，框内「身份 · 姓名：」加台词，右上「按住 ctrl 跳过」。（`03`）
- 海域等区域左侧边缘有可展开的「**附近的人**」抽屉，显示人数。（`05`）

### 2.4 战斗
- 全屏场景；玩家在左，对手在右。（`02`、`04`、`06`）
- 顶部两侧：头像、名字、灵气数、血条、一排状态图标（带层数）。
- 底部一整块装饰操作盘：左边 2×5 神通格（快捷键 1–5、Q W E R T，另有一格法宝 D）；中间阴阳盘「**回合结束**」；右边五行灵气及数量；最右「帮助」「记录」「逃跑」。
- 战斗中**没有任何其他界面元素**。

### 2.5 突破结果
- 黑底，中央**书法大字**「筑基」，周围飞鱼、山峰装饰；下方一段描写，「筑基初期」，获得的加成（「【筑基洗髓】额外提升生命值 +54」），底部「确定」。（`09`）

### 2.6 角色总面板
- 全屏。上方**屋檐造型的标签栏**：属性、悟道、功法、神通、物品、声望、系统；左侧一个「?」，右上关闭。（`14`、`15`、`16`、`18`）
- **属性**：左侧两盏灯（生命、修为）；中间人物剪影与境界；右侧基本属性（年龄、寿元、资质、神识、悟性、遁速、修炼速度）、心境 / 丹毒 / 灵感、门派与职位、五行灵根数值。
- **物品**：左半人物全身立绘，周围一圈装备槽；右侧物品格子，可按品阶、类型筛选，底部灵石数与「整理」。
- **悟道**、**声望**：各自一页图形化的进度。

### 2.7 其他独立界面
- **任务卷轴**：标签「任务 / 传闻 / 委托」；左边列表，右边详情（剩余时间、任务进度、任务描述），可「追踪」。左上「返回」。（`17`）
- **炼丹**（`10`）、**炼器**（`11`）、**拍卖会**（`08`）、**论道**（`13`）：各自全屏，统一的「离开 / 退出」按钮回到上一个界面。

### 2.8 人物交互（`人物交互_城市场景_旧版`、`人物交互_地图人物菜单`、`人物交互_03`–`05`）
- 点人物后，画面中央是一个**大圆框半身立绘**，下沿写名字；**两侧各一列选项按钮**：左列交谈、论道、交易、切磋、赠礼，右列请教、查看 / 探查、威胁 / 索取、截杀（敌对选项用红底）、离开。背景场景或地图仍然可见。
- 场景和大地图上都是同一个交互菜单。
- **赠礼**另开一页：左侧自己的物品格（可按品阶、类型筛选，底部「整理」），右侧对方「感兴趣的物品」提示、选中的物品与情分变化，底部「返回」「确定」。
- **对话**：底部横条对话框，左下角半身立绘压在框边，框内「身份 · 姓名：」与台词，右上「按住 ctrl 跳过」；需要选择时，选项竖排在画面上方居中。

### 2.9 附近的人（`多人场景_01`、`02`）
- 屏幕**左边缘一个竖排抽屉**「附近的人 N」加展开箭头；展开后是一列人物小卡（头像、关系「陌生 / 相识 / 熟悉」、名字、身份），背景仍可见，再点箭头收起。城镇场景里同样用这个抽屉（`人物交互_城市场景_旧版` 中有 4 人）。

### 2.10 闭关面板（`闭关_01`–`03`）
- 入口：在大地图洞府节点上点「进入」，弹出竖排选项（去某地 / 进洞府 / 改名）；进洞府后，右下竖排圆形按钮「突破」「闭关」「离开」。
- 闭关面板是叠在场景上的一张大纸卷：
  - **左侧竖排页签**：修炼、领悟、突破、感悟（突破也在这里）。
  - **中间「重要事件」列表**：各地事件与剩余时间（英杰会剩余 0 年 10 月 24 日、宗门大比剩余 9 年……），提醒闭关别错过。
  - **右侧**：中央「总修炼速度 每月 N」，四周是各项来源（功法、资质、地脉、心境的数值或加成）。
  - 下方「选择闭关时间」滑条，两侧箭头微调，显示「N 年 N 月」，再下面「开始闭关」；右上关闭。

### 2.11 商店 / 买卖（`商店_草药交易`、`商店_法宝交易`）
- 三栏：**左**是自己（头像、身份与名字，物品格，左边竖排类别页签：全部、法宝、丹药、秘籍、材料、草药、其他；品阶 / 类型筛选；底部自己的灵石）；**中**是「出售」「收购」两列待交易格，下方本次净额（−12150 / +40032）；**右**是商家（头像、名字、「兴趣」，同样的页签与物品格，底部商家灵石）。
- 底部「返回」「确定」。点物品放进中间待交易格，确定后才成交。

### 2.12 功法与神通页（`功法_配置页`、`神通_配置页`）
- 都在总面板里，**左边是已装备的配置**，**右边是可用的全部**。
- 功法：左边按位置摆放的槽位（遁术、主修、辅修 ×4、元婴功法），左上有方案切换；右边图标格，左侧竖排五行页签（全部、金、木、水、火、土、杂），上一页 / 下一页翻页。
- 神通：左边两列快捷键槽（1–5、Q W E R T），左上方案切换；右边图标格，可按品阶、属性筛选，滚动浏览。

## 3. 本作对应方案

### 3.1 常驻信息（只在场景和大地图界面显示）
- **左上**：头像、道号、境界；气血、灵力、修为三条细条；下面一排图标按钮：**人物**（总面板）、**行囊**、**功法**、**编年史**。
- **右上**：日期、所在地；「**任务**」卷轴按钮（有新内容时加红点）。
- 去掉：左侧栏、修行手记框、底部状态栏、顶部按钮排。最近一两条记载以淡出的小字浮在左下角，几秒后消失；点它打开编年史。
- 保存 / 读取 / 新旅程 / 设置移进总面板的「系统」页；F5、F9 等快捷键照旧。

### 3.2 界面清单

| 界面 | 进入方式 | 内容 | 退出 |
|---|---|---|---|
| 场景 | 抵达某地 | 整屏地点图，场景（静室、长街、药铺……）为竖排纸条标签；此地人物在一侧排成立绘小卡（人多时折叠为「此地人物 · N」抽屉）；有闭关的地点右下竖排功能按钮（闭关、休整、突破） | 右下「离开」→ 大地图 |
| 场景内某处 | 点纸条标签 | 该处的行为（采集、买卖、委托、传功……）以面板叠在场景上 | 关闭回场景 |
| 附近的人 | 场景、大地图左边缘的竖排抽屉「此地人物 N」 | 展开为一列人物小卡（头像、好感阶段、名字、身份），背景仍可见 | 再点收起 |
| 人物交互 | 点人物小卡 | 中央大圆框立绘与名字，两侧两列选项：左列交谈、赠礼、切磋、交易等，右列查看（资料与往来）、委托或其他人物专属选项、离开；敌意选项（斗法）用暖红底 | 「离开」回原界面 |
| 赠礼 / 交付 | 人物交互里的「赠礼」或需要物品的选项 | 左边自己的物品格（按类别筛选），右边选中的物品与好感变化；返回 / 确定 | 回人物交互 |
| 商店 | 长街丹铺、云溪药铺、钱货郎等 | 三栏：左自己的物品格与灵石，中「出售」「购入」待交易格与净额，右商家的货与价格；返回 / 确定，确定后才成交 | 回场景 |
| 大地图 | 场景点「离开」或「舆图」 | 整屏舆图，地名纸条，人物标记；选目的地后标记沿路线移动、日期随之走；途中遇袭切到战斗，打完回地图继续走 | 抵达即进入该地场景 |
| 对话 / 事件 | 事件触发 | 有插图时整屏插图在上；底部对话框（立绘 + 文字逐字显示）；选项列在对话框上方 | 选完回到原界面 |
| 战斗 | 遇袭、切磋、挑战 | 整屏斗法舞台；顶部双方血条；底部操作盘：神通格（按键标注）、守御、撤离、记录 | 结束后回原界面 |
| 闭关 | 静室右下竖排按钮「闭关」 | 叠在场景上的大纸卷。左侧页签：修炼、突破。中间「近期大事」：约定与当前目标里有期限的事及剩余时日（妖蟒、拍卖、小比……）。右侧：中央每月修为，四周来源（灵根、心法、法宝、心境收益）；下方时长滑条（按月）与「N 年 N 月」，预览修为、心境变化、会不会停在瓶颈；「开始闭关」后播时间流逝的演出 | 关闭回场景 |
| 突破 | 闭关面板的「突破」页，或静室右下「突破」 | 准备（筑基丹、修为是否足够）→ 突破演出 → 结果页（书法大字境界名、描写、加成、确定） | 确定回场景 |
| 总面板 | 左上「人物」或快捷键 | 标签：属性（气血、灵力、修为、灵根、心境、寿元、门派）、功法（左边已装备：心法 2 槽与法宝 3 槽；右边全部已学，按五行页签）、神通（左边 4 个快捷键槽，右边全部已学，按品阶、属性筛选）、行囊（左人物立绘与装备，右物品格与类别页签）、相识（列表 + 资料卡与往来）、编年史、系统（存读档、设置、新旅程） | 右上关闭 |
| 任务卷轴 | 右上「任务」 | 标签：当前目标、委托、传闻、约定；左列表右详情 | 返回 |
| 标题界面 | 开局 | 保持独立整屏 | — |

## 4. 分步实施

1. **骨架**（已完成）：`main.gd` 改成界面管理器，`current_screen()` 按状态选屏——`place`、`map`（世界，显示 HUD）、`full`（事件、故事、斗法、结局，整屏无 HUD）、`panel`（人物面板）、`scroll`（任务卷轴）。`hud.gd` 做常驻的左上、右上两块与左下近事、底部提示；侧栏拆成 `status_view.gd`（属性页）与 `tasks_view.gd`（当前目标、委托、约定），存读档等移进 `system_view.gd`（系统页）。现有视图原样搬进对应界面：地点与舆图暂放在右侧窗口，背景铺地点横幅或舆图（整屏场景待第 5 步与补图）。面板与卷轴有标签行与「关闭 Esc」，HUD 按钮再点一次也关闭。
2. **大地图与行路**：整屏舆图上标记沿路线移动、日期跟走；遇袭切战斗、打完回地图。
3. **战斗**：全屏斗法界面与底部操作盘。
4. **闭关与突破**：独立界面与演出（规则不变，只加演出）。
5. **场景与人物交互**：整屏场景、纸条标签、左边缘人物抽屉、中央立绘两侧选项的交互菜单、赠礼页、三栏商店。
6. **总面板各页**：属性、功法、行囊、相识、编年史、系统。
7. **收尾**：统一视觉；1280×800 与 1000×640 检查；补测试与文档。

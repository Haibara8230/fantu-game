# 界面改版：按界面切换（参照《觅长生》）

> 状态：规划中（2026-10-12）。参考截图在 `PNG/`（只在本地，不进 git）；还缺的截图见第 5 节。确认后按第 4 节分步实施。

## 1. 为什么改

现在所有内容挤在一个窗口里：顶部一排按钮，左侧栏（状态、当前目标、委托、相识、约定、行程），中间面板，底部修行手记和状态栏。斗法、事件、突破只是中间面板换了内容，四周的框架一直都在，信息多而杂。

目标：像《觅长生》一样**按界面切换**。场景、大地图、战斗、突破、各种面板各占整屏；常驻信息压到最少，其余点开才看。

**原则**
- 照搬的是**结构**：界面怎么分、信息放在哪、怎么进出。截图里的美术（图标、边框、屋檐标签栏、书法字、装饰）不能拿来用，外观全部用本作的二维手绘风格重新做。
- 规则不动。改版只涉及界面与演出；存档、玩法、数据格式不因改版而变。
- 每一步做完都能玩，测试照常全部通过。

## 2. 《觅长生》的界面结构（据 `PNG/steam/` 的官方截图）

### 2.1 常驻信息：只有左上和右上两小块
- **左上**：圆形头像；道号；生命条（红）；修为条（蓝）。下面一排 4 个圆形图标按钮，打开功法、物品、任务一类面板。（`01`、`03`、`07`）
- **右上**：日期（`510年1月15日`）；当前所在地（带小图标）；一个卷轴形「任务」按钮。
- 除此之外屏幕上**没有常驻的侧栏或日志**，整屏留给场景本身。
- 特殊状态在顶部正中挂一小块（洞府里的「雷劫 剩余 48 年」，`12`）。

### 2.2 场景界面（城镇、宗门、洞府）
- 整屏一张**俯视角手绘场景图**，各处建筑上挂**竖排纸条标签**（藏经阁、炼丹房、客栈、灵药堂、传送阵……），点标签进入。（`01`、`07`）
- 右下角圆形「**离开**」按钮；有传送阵的地方在它上面叠「传送阵」。
- **洞府**的右下角是一列竖排圆形功能按钮：神游、装扮、**闭关**、离开。闭关从这里进。（`12`）

### 2.3 大地图（行路）
- 整屏手绘地图；地名用竖排纸条标在节点旁；一个 Q 版小人站在路线上，沿路线移动。（`03`）
- 大地图上**直接弹对话**：底部一条横向对话框，左侧半身立绘，框内「身份 · 姓名：」加台词，右上「按住 ctrl 跳过」。（`03`）
- 海域等区域左侧边缘有可展开的「**附近的人**」抽屉，显示人数。（`05`）

### 2.4 战斗
- 全屏场景；玩家在左，对手在右。（`02`、`04`、`06`）
- 顶部两侧：头像、名字、灵气数、血条、一排状态图标（带层数）。
- 底部一整块装饰操作盘：左边 2×5 神通格（快捷键 1–5、Q W E R T，另有一格法宝 D）；中间阴阳盘「**回合结束**」；右边五行灵气及数量；最右「帮助」「记录」「逃跑」。
- 战斗中**没有任何其他界面元素**。

### 2.5 突破结果
- 黑底，中央**书法大字**「筑基」，周围飞鱼、山峰装饰；下方一段描写，「筑基初期」，获得的加成（「【筑基洗髓】额外提升生命值 +54」），底部「确定」。（`09`）

### 2.6 角色总面板
- 全屏。上方**屋檐造型的标签栏**：属性、悟道、功法、神通、物品、声望、系统；左侧一个「?」，右上关闭。（`14`、`15`、`16`、`18`）
- **属性**：左侧两盏灯（生命、修为）；中间人物剪影与境界；右侧基本属性（年龄、寿元、资质、神识、悟性、遁速、修炼速度）、心境 / 丹毒 / 灵感、门派与职位、五行灵根数值。
- **物品**：左半人物全身立绘，周围一圈装备槽；右侧物品格子，可按品阶、类型筛选，底部灵石数与「整理」。
- **悟道**、**声望**：各自一页图形化的进度。

### 2.7 其他独立界面
- **任务卷轴**：标签「任务 / 传闻 / 委托」；左边列表，右边详情（剩余时间、任务进度、任务描述），可「追踪」。左上「返回」。（`17`）
- **炼丹**（`10`）、**炼器**（`11`）、**拍卖会**（`08`）、**论道**（`13`）：各自全屏，统一的「离开 / 退出」按钮回到上一个界面。

## 3. 本作对应方案

### 3.1 常驻信息（只在场景和大地图界面显示）
- **左上**：头像、道号、境界；气血、灵力、修为三条细条；下面一排图标按钮：**人物**（总面板）、**行囊**、**功法**、**编年史**。
- **右上**：日期、所在地；「**任务**」卷轴按钮（有新内容时加红点）。
- 去掉：左侧栏、修行手记框、底部状态栏、顶部按钮排。最近一两条记载以淡出的小字浮在左下角，几秒后消失；点它打开编年史。
- 保存 / 读取 / 新旅程 / 设置移进总面板的「系统」页；F5、F9 等快捷键照旧。

### 3.2 界面清单

| 界面 | 进入方式 | 内容 | 退出 |
|---|---|---|---|
| 场景 | 抵达某地 | 整屏地点图，场景（静室、长街、药铺……）为竖排纸条标签；此地人物在一侧排成立绘小卡（人多时折叠为「此地人物 · N」抽屉）；有闭关的地点右下竖排功能按钮（闭关、休整、突破） | 右下「离开」→ 大地图 |
| 场景内某处 | 点纸条标签 | 该处的行为（采集、买卖、委托、传功……）以面板叠在场景上 | 关闭回场景 |
| 人物交互 | 点人物小卡 | 底部对话框式：左侧立绘、姓名与身份、台词；上方一列选项（交谈、赠礼、切磋、交易……）；「往来」和资料收在一个可展开的小页 | 关闭回场景 |
| 大地图 | 场景点「离开」或「舆图」 | 整屏舆图，地名纸条，人物标记；选目的地后标记沿路线移动、日期随之走；途中遇袭切到战斗，打完回地图继续走 | 抵达即进入该地场景 |
| 对话 / 事件 | 事件触发 | 有插图时整屏插图在上；底部对话框（立绘 + 文字逐字显示）；选项列在对话框上方 | 选完回到原界面 |
| 战斗 | 遇袭、切磋、挑战 | 整屏斗法舞台；顶部双方血条；底部操作盘：神通格（按键标注）、守御、撤离、记录 | 结束后回原界面 |
| 闭关 | 静室等处的「闭关」 | 选择时长（1 月 / 半年 / 1 年……或滑条），预览修为、心境、是否触及瓶颈；确认后一段时间流逝的演出 | 结束回场景 |
| 突破 | 静室「突破」 | 准备页（筑基丹、修为是否足够）→ 突破演出 → 结果页（书法大字境界名、描写、加成、确定） | 确定回场景 |
| 总面板 | 左上「人物」或快捷键 | 标签：属性（气血、灵力、修为、灵根、心境、寿元、门派）、功法（神通 4 栏 + 心法 2 栏 + 法宝）、行囊（物品格 + 筛选）、相识（列表 + 资料卡与往来）、编年史、系统（存读档、设置、新旅程） | 右上关闭 |
| 任务卷轴 | 右上「任务」 | 标签：当前目标、委托、传闻、约定；左列表右详情 | 返回 |
| 标题界面 | 开局 | 保持独立整屏 | — |

### 3.3 现有内容的去向

| 现在的位置 | 改版后 |
|---|---|
| 左侧栏：状态 | 左上常驻 + 总面板「属性」 |
| 左侧栏：当前目标、委托、约定 | 任务卷轴 |
| 左侧栏：相识 | 总面板「相识」；场景里只显示此地人物 |
| 左侧栏：行程、「展开舆图」 | 大地图界面本身 |
| 顶部：此地 / 舆图 / 行囊 / 功法 | 场景、大地图、总面板各自的入口 |
| 顶部：保存 / 读取 / 新旅程 / 设置 | 总面板「系统」 |
| 修行手记 | 左下淡出小字 + 编年史 |
| 底部状态栏（操作结果文字） | 场景内短暂浮出的提示 |
| 中间面板的事件、斗法、故事卡 | 对话 / 事件界面、战斗界面 |
| 新手指引 | 改为贴在对应按钮旁的小提示气泡 |

## 4. 分步实施

1. **骨架**：`main.gd` 改成界面管理器（当前界面 + 叠加层），做好常驻两块、总面板标签框架、任务卷轴框架；现有视图先原样搬进对应界面。测试改为按界面查找控件。
2. **大地图与行路**：整屏舆图上标记沿路线移动、日期跟走；遇袭切战斗、打完回地图。
3. **战斗**：全屏斗法界面与底部操作盘。
4. **闭关与突破**：独立界面与演出（规则不变，只加演出）。
5. **场景与人物交互**：整屏场景、纸条标签、人物小卡、对话框式交互。
6. **总面板各页**：属性、功法、行囊、相识、编年史、系统。
7. **收尾**：统一视觉；1280×800 与 1000×640 检查；补测试与文档。

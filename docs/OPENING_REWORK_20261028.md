# 开局天赋重做：把强度改成取舍

2026-10-28。取代 `OPENING_DRAFT_20261022.md` 中的六页单选、按颜色定价和直接出售旧版高阶天赋的方案。用户反馈高天赋角色失去游戏体验，本次实际修改新建角色规则；旧存档和 NPC 的历史天赋不做数值迁移。

## 问题与修正

旧版只模仿了选择流程，效果仍是另一套夸张数值：仙人转世提供修炼 +400%、突破把握 +120、品质提升 +320%；天妒英才修炼 +640%；混沌灵体同时给修炼 +360% 和全伤害 +200%。此外，选择高颜色天赋还会隐式增加资质评分，形成第二重收益。

新开局使用独立的 `mcs_` 天赋，共 30 项，不再出售这些旧版大奖。颜色只负责显示，不额外增加资质；价格在 `opening.json.costs/refunds` 逐项定义，不从颜色推导。新天赋不进入 NPC 和旧版随机出生池，保留其生成顺序及结果。

## 开局规则

| 选择 | 现行规则 |
| --- | --- |
| 角色点数 | 天谴之人 -5、凡人修仙 0、红尘众生 10、天命主角 20、异世傲天 40；默认 20 |
| 灵根价格 | 天／双／三／四／五灵根分别 14／10／6／2／0 |
| 分类 | 出生身世、先天体质、儿时经历、青年经历 |
| 组合 | 各页可多选；家庭出身互斥，魂穿异世可与一个家庭并选 |
| 取消 | 再次点击已选项取消；页面的普通项清空本页 |
| 缺陷 | 在点数不足时仍能选，因而负预算角色能通过真实代价启程 |
| 最终检查 | 灵根完整且不重复；项目属于对应页；无重复、互斥、未知项；余额非负 |

“角色点数”不再误标为“难度”。本轮没有新增原作独立的五档战斗难度，战斗基础规则继续使用项目现有配置。

## 影响实际游玩的数值

悟性基础为 20；书香门第 +10、过目不忘 +20、转世仙人 +30、心智有损 -5。参悟功法和修习功法层数都执行：

`耗时 = max(1, ceil(原参悟耗时 × 20 / 悟性))`

原参悟耗时仍包含灵根相合、旧天赋、宗门职务的修正。悟性不增加打坐修为、伤害、突破把握或品质；角色页与开局总览明确显示这一点。

| 项目 | 现在的效果 |
| --- | --- |
| 转世仙人（16 点） | 悟性 +30；每跨越一个大境界额外 1 悟道点；化神起始仙性 +2 |
| 先天道体（3 点） | 修炼 +10%，与玄阴绝脉互斥 |
| 玄阴绝脉（返 3） | 修炼 -10% |
| 五行体质（各 1 点） | 对应抽气权重 +5；不增加吸气总数和伤害；保留本项目的对应灵根限制 |
| 神魔血脉／羸弱多病 | 初始气血 ±5，境界阶段相对炼气初始值的基础气血增长 ±20%；互斥 |
| 魂穿异世 | 神识固定 +3，不随大境界倍率放大 |
| 轻功高手／先天残疾 | 遁速固定 ±3；影响先手和逃离，互斥 |
| 大病一场／修身养性 | 寿元 -30／+10 年，互斥 |
| 练武世家／神奇温泉／先天武者 | 固定气血 +10／+10／+20 |
| 流浪孤儿 | 固定气血 -10，与其他家庭出身互斥 |

例如：40 点选择天灵根 14、书香门第 2、魂穿异世 1、转世仙人 16、先天道体 3、过目不忘 4，刚好用完。悟性 80，100 日基础学习缩至 25 日；同灵根下打坐速度仅为无天赋角色的 1.1 倍，起始伤害和突破品质没有额外赠送。高天赋的优势在于学习构筑、争取时间，而非直接跳过养成。

## 原作参考与本项目适配边界

参考了 [BWIKI 全天赋简评](https://wiki.biligame.com/mcs/全天赋简评) 的角色点数、家庭互斥和“悟性／修为不同”的效果方向；该页标记为过期攻略，不能当成最新版本完整数值表。[BWIKI 构筑选择器](https://wiki.biligame.com/mcs/Widget:测试) 用于交叉核对灵根与条目费用，未采用其中的 99 点扩展角色。

这是对开局预算与成长结构的实装重做，不是原作全天赋及配套系统的完整移植。以下差异在项目现有系统中明确适配，不能对外声称与原作完全相同：

- 商贾提供 90 灵石，修真家族提供对应灵根的黄阶心法玉简；没有套用原作的一万灵石和专属功法，以免破坏当前物价。
- 道心坚定／惨遭退婚采用心境获得 +20%／-30%，而不是原作初始心境 ±30；本项目初始心境为零且存档不接受负值。这两个项目互斥，缺陷影响后续获得，不会被零下限吞掉。
- 药堂学徒为采集 +20%；命犯桃花为好感获得 +20%；后山洞窟给当前装备体系中的凡品法袍；坠崖奇遇给一株百年灵芝，服务于炼丹准备。
- 基础悟性 20、每境额外悟道点 1、气血增长的计算基数，以及额外的正负经历互斥属于项目适配。灵根既有修炼倍率未改。
- 神秘绿瓶、神秘贝壳、龙族／异族等特殊天赋及其完整独有玩法尚未接入本次目录；没有使用同名空效果或简单巨额伤害替代。先天道体目前也没有额外筑基仪式减难。

# 开发路线

## 当前决定
- 引擎：Godot；脚本：GDScript；主要平台：Windows。
- 目标：可离线游玩的完整单机游戏。
- 暂定首版：2D 地点探索、回合制斗法、按月份修炼推进。
- 名称、战斗形式、美术风格和世界观都仍可调整。

## 首章验收
创建角色 → 修炼 → 采草或斗法 → 坊市交易 → 购买筑基丹 → 突破 → 击败妖蟒。
支持中途退出再继续，允许失败后恢复；同时保留独立手动存档。

## 第二阶段：玩法深度
- 可学习和装备的功法；战斗流派与效果结算。
- 正式物品定义、背包和奖励表。
- 任务条件、奖励与阶段推进。
- 炼丹与材料消耗；完善资源获取和消费。
- 在扩展境界前，确认这一阶段的基础玩法足够有趣。

## 第三阶段：世界与故事
- 地区、NPC 身份、关系与宗门。
- 时间推进触发事件，而非每帧模拟全部 NPC。
- 有明确起点、目标和结局的剧情章节。
- 存档迁移、内容 ID 的稳定性与旧版本兼容。

## 第四阶段：发行准备
- 正式美术、音效、设置界面与教程。
- 不同分辨率、键鼠输入、性能与长时间存档验证。
- Windows 导出模板、独立包、许可声明与发布材料。

## 工程原则
- 引擎版本固定，确认兼容后再升级；当前验证版本 4.7.2。
- 内容引用稳定 ID，存档不保存 UI 节点。
- 功法和敌人数值使用独立配置，规则保持单一来源。
- 避免把 NPC、任务、炼丹等系统提前堆成空框架，按实际玩法逐步实现。

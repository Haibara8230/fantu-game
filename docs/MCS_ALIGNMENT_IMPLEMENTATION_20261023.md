# 觅长生体验对齐：第二轮实施

日期：2026-10-23。对应用户确认的七项顺序，以及「继续一直做完所有改动」。七项均已接入可操作实现；原作全量内容、逐像素观感和未取得参考的动作不在“已一致”的声明内。已确认的左右斗法布局、中央轮盘与十个神通槽保持为本轮视觉基准。

## 2. 支付灵气的生／同／克

规则模块 `scripts/core/qi_relations.gd` 仅读取本次实际支付。两种相生灵气为「生」、同一种为「同」、两种相克灵气为「克」；一颗或三种不同灵气不制造标签。只触发该神通明确配置的效果，不给所有攻击附加统一的目标属性克制倍率。

中央只显示本招真正能触发的标签。预览、支付检查、实际效果使用同一计算。上一招属性引出的「连击」独立保留，不能用上一招代替本次配气。五行印改为按「生」额外吸气，并加入每回合一次的后继无力。项目原有气击、部分神通原型也有配气触发；这些附加量在配置中注明为项目适配值。

## 3. 尘沙流派样板

`data/combat_flows.json`、`scripts/core/dust_flow.gd` 提供普通商店可购、可研读、可装配的一整套循环：

1. 「卸甲」先获得护罩，再把全部护罩转为尘。
2. 「化沙」将尘转为对手身上的沙。
3. 「还尘」收回对手全部沙，转为自身尘。
4. 「绝尘」消耗固定层数尘造成伤害，上一招为火时追加伤害。
5. 「万土归尘」在支付后把手中剩余土灵气转尘。
6. 「化尘诀」提供还尘后护罩、化沙后追加伤害；「万尘归灵诀」提供还尘后下回合聚气。

费用、分境界消耗／效果按官方公告及 2023-01-18 图鉴记录交叉核对；玉简价格、学习时间和功法修炼加成为项目数值。化沙、还尘、万土归尘每回合一次。条件不满足时不支付、不推进随机流；敌我分开记资源与使用回合，敌方规划也检查这些条件。资源图标、事件演出和存读档均已接入。

云溪坊市出售五门神通及两门心法的玉简。用户可自行运行 [`preview_dust_flow.cmd`](../preview_dust_flow.cmd)，进入配好神通和心法的独立斗法样板。预览的存档、设置及日志留在 `.tmp/art_preview/`，不覆盖正式旅程。本轮自动化没有启动这个可见预览。

## 4. 独立悟道成长

新增「悟道」页：金木水火土、气体剑神阵丹器共十二道，五个道境。道境理解、待吸收感悟、悟道点和已选节点各自记录。学习与功法层数成长直接积累理解；斗法、论道积累待吸收感悟，在允许闭关的地方按实际日数吸收并付房钱。论道三日、交情门槛与冷却从配置读取。

本轮接入一组可发挥实际效果的节点，包括持气御敌、五行增伤与吸气、留气／开场／每回合吸气、气血与减伤、剑招增益、神识、阵法驱动、采药／丹毒／成丹、炼器时间和灵纹。选取需满足理解、点数及同道前一已定义层，不能从第一层跳到第五层；有后层依赖时不能遗忘中间层，永久节点不能退款刷上限。

较高品阶的新学习增加悟道门槛，旧档已学功法继续可用。旧档没有悟道字段时从已学功法派生初始理解，在第一次积累时建立独立记录，不重复奖励。新增字段均在恢复前校验。

这是一组节点和本项目进度的映射，不等于原作全部悟道树；论道当前为人物交互和感悟结算，并未制作原作完整论道卡牌玩法。数据中的学习经验、悟道点来源和节点映射边界有单独说明。

## 5. 战前药力

继续执行用户定案：**战前服用，开战后不能再吃丹药**。服用时扣除物品，首次开场一次性转入本场药力，连战不重新获得。

| 丹药 | 生效范围 |
|---|---|
| 原有回气丹／上品回气丹 | 下一场开场额外吸气；兼容原有准备字段 |
| 凝神丹 | 本场神识 +1 |
| 龙虎丹 | 首回合神通伤害 +1 |
| 聚甲丹 | 开场护罩 +5 |
| 冰元丹 | 前三回合免疫灼烧 |
| 厚土丹 | 本场土系伤害 +1 |
| 磊叠丹 | 本场每回合额外吸收一颗土气 |

同药力组不能重复准备，不同组可以并用。行囊、属性页展示待生效药力，斗法状态区展示本场药力；首回合及三回合药效到期隐藏。原作药效经图鉴交叉核对，售价及本项目使用入口为适配。已经战斗中的旧药力存档不重放开场。

## 6. 其他界面

- 神通：两排十个可选择槽位，右侧已学列表；先选槽再点功法即可替换。功法页使用主修／辅修槽位，保留层数与闭关参悟入口。
- 行囊：左侧佩戴与药力，右侧类别筛选和六列物品格；选中物品后显示详情与服用、研读、装备等操作。
- 交易：待售、交易清单与持有物各自滚动，保留价格、数量和结算规则。
- 人物：立绘与姓名在左，简介与交情居中，交往命令集中在右侧滚动；查看和离开始终可用，论道入口接入现有人物关系。
- 闭关：常用时长按钮即时更新出关预览；领悟页展示待吸收感悟并可直达悟道。现有突破准备、概率分解与护法保留。

沿用现有手绘立绘、图标和卷轴皮肤，没有改为写实人物。规则测试和控件范围检查无法替代字体、透明边缘与遮挡的图形验收。

## 7. 可调整丹方、多材料炼器

炼丹可从既有丹方切换「调整丹方」，自由增减可用主药，按生机、聚元、凝练、筑基药性判断是否满足需求；药引、火候、借炉及成丹预览继续结算。药性不足、负数、分数、未知药材与超量配置在扣除前拒绝。原固定丹方路径保留。当前使用本项目四种药材，药性强度并非原作全量药材数据。

炼器可投入多种材料；主材决定器型，成器品阶按最低材料品阶，材料家族提供可定向词条。玩家可指定预算内词条，空余槽仍按世界种子生成；预览列出实际每种材料和数量、费用、时间、已选效果。器道节点解锁朱雀／白虎灵纹，成器保留为独立宝物实例；祭出增伤与自身损伤已接入战斗。灵纹数值是项目适配，非原作所有器纹。

自动检查全部带 `--headless`，不打开或聚焦游戏／编辑器窗口。`check.cmd` 加入尘沙、悟道、战前丹药与丹器、界面操作四套专项；所有日志和汇总在 `.tmp/alignment_*.log` 与 `.tmp/alignment_verification.json`。

`git diff --check` 通过。本轮没有自动启动可见预览，没有对玩家存档执行写入或迁移；旧字段缺省、满血悟道上限、非法新字段原子拒绝及连战药力不重复触发均有后台断言。丹药六种图标为沿用现有矢量部件风格绘制的原生 SVG。

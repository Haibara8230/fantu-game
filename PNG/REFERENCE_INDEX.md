收集日期：2026-10-12。对应 `docs/UI_REDESIGN.md` 第 5 节的五类待补资料。本批 16 张来源图片已下载并逐张查看，保持来源图原样；另有两张编号缩略总览。图片仅供本地结构参考，由 `.gitignore` 排除，并由 `.gdignore` 排除 Godot 导入。

## 分类覆盖

| 需求 | 已有参考 | 仍需细化的状态 |
|---|---|---|
| 人物交互 | 场景/地图菜单、赠礼选择、底部对话与选项 | 交易入口到返回人物的连续画面，切磋前后返回 |
| 闭关 | 地图入口 → 洞府功能按钮 → 时长选择面板 | 改动时长后的预览变化、确认后演出与出关；本作心境/瓶颈提示须按自身规则设计 |
| 商店 / 买卖 | 草药、材料、法宝，已放入待交易物品及净额 | 数量弹窗、交易确认后的状态，钱不够等反馈 |
| 功法 / 神通 | 完整总面板标签、装备区域、技能库、筛选与分页 | 选中详情、替换槽位、悬停提示 |
| 多人场景 | 人物抽屉收起/展开、4 人场景列表 | 大量人物超过一屏时的滚动/筛选状态 |

## 如何用于本作

- 人物界面应区分“选择行为”“对话”“选择赠礼物品”三个状态；中央人物菜单和底部对话框有不同用途。本作按设计文档采用底部对话框，不必照搬环形菜单。
- 闭关将耗时选择、收益信息与临近事件放在同一准备页；本作额外展示心境收益递减和瓶颈，由现有规则计算。
- 商店采用双方物品区与本次交易区，明确区分选中物品和最终确认，底部显示灵石变化。
- 功法/神通分开显示已装备配置与可用列表，筛选保持可见；本作沿用自身 4 神通、2 心法与法宝配置。
- 人物少时直接展示卡片，人多时展开抽屉；抽屉覆盖场景一侧，关闭后恢复场景空间。
- 只参考布局、信息层级与进出方式，边框、按钮、图标和人物外观由本作二维手绘素材实现。

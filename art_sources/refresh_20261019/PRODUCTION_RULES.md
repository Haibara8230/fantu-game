# 生图目录、旧图规格与引用规则

用户最新授权：继续做完全部图。生图目录重定向到D盘后使用内置生图工具；规格参考旧图，明确引用规则，各类画风与参考样张不变。原先后期暂缓的范围已由本次授权更新。

## 图片实际存储

本机已建立NTFS目录联接：`C:/Users/Kuroro/.codex/generated_images` → 当前项目 `D:/claude/flash/.tmp/imagegen_storage/generated_images`。C盘路径只是工具看到的目录入口，图片负载实际存D盘；未搬动Codex的配置、登录信息或应用日志。联接应长期保留，不要删除D盘目标目录。

每次生图前从项目根目录运行：

```powershell
& .\tools\art\redirect_imagegen.ps1 -VerifyOnly
```

检查必须确认目录类型为Junction、最终目标为当前D盘项目，直接向D盘目标写入探针，再通过联接只读比对相同字节；不向C盘路径发起写入。报告在 `.tmp/imagegen_storage/redirection.json`。安装联接用不带 `-VerifyOnly` 的同一脚本；脚本不会搬动、删除或覆盖已有普通目录。若目录已存在但不是正确联接，停止并说明；禁止仅凭提示词中的D盘路径判断存储位置。

生成后再次解析工具返回文件的真实路径，验证位于上述D盘目标，再原样复制到本批 `output/`。保留工具原始文件与原生输出，不把项目资源只留在工具缓存里。若工具使用其他尚未核验的目录，停止后续调用。

## 继承旧图规格

每项 `new_asset_briefs.json` 的 `technical_spec` 明确记录旧图路径、SHA-256、尺寸、比例、模式／透明度，以及适用的图集定义。新增图片选同用途旧图作为规格依据；已有替换图片直接使用自己的 `inputs.json` 定义。旧图只承担它声明的用途，不因继承尺寸就沿用已废弃的剧情或更换画风。

| 类型 | 规格与输出要求 |
|---|---|
| 头像与独立人物 | 按对应旧头像尺寸、构图、底色或透明要求；同人多状态保持身份。普通池逐张继承本图规格。 |
| 动作与妖兽图集 | 原尺寸、行列、帧序、朝向、frame_regions、脚底基线与透明度均继承；新怪未定实际战斗用途时不生成。 |
| 地点、场景、事件、地图、斗法背景 | 按技术锚点记录的原生尺寸和比例；场景还要保留现有横幅窗口所需的中央4:1安全区。文字、标记、角色和规则读数按原规范由独立层承担。 |
| 透明插画与特效 | 按旧图检查真实alpha；新特效的时长／帧数未由消费者确认时先待办，不擅自推断动画结构。 |
| SVG | 保留旧SVG的viewBox、尺寸、透明和分层组合，由既有生成器／矢量编辑维护，不调用位图工具统一栅格化。 |

内置工具不提供可靠的指定输出尺寸参数，提示词请求的尺寸不等于实测尺寸。交付同时记录 `target_dimensions` 与 `native_dimensions`：保留原生文件，尺寸不同时标记待集成裁切／适配，不拉伸、不把实测尺寸冒称目标尺寸。若中央安全区不完整，先定向重生成；本轮不通过像素滤镜或重画风处理掩盖不兼容。

## 明确引用角色与版本

引用入口为 `PRODUCTION_MANIFEST.json`。每项需求的 `reference_bindings` 与 `dependencies` 都解析到该清单，读取对应路径并核对SHA-256。路径或哈希变化后先复核版本，再更新清单；不能静默改为另一张相似参考。

- `dimensions_alpha_layout_only`：旧图仅约束技术规格／布局，不把旧剧情、宗门身份或背景画法当成新内容要求。
- `drawing_style_only`：对应已确认分类样张，约束轮廓、色块、阴影、材质概括和细节密度，不复制人物身份或建筑规模。人物C版只用于人物；室外支路按原规范引用04地点画法，室内继续07。
- `original_game_style_only_no_copy`：原作截图只说明对应类别画法，不能复制角色、文字、UI、水印或完整原作地点。
- 人物出现时必须引用 `identity_registry` 中该人物的具体候选和哈希；柳寒舟受伤版本有单独例外路径。晏无咎等尚未定脸者由02批先交身份，依赖其出场的图等待，不拿风格样张中的沈墨当其他人物。
- `motif:old_city_seal_candidate` 是10批的城徽候选，连同其矢量总览的指定单元格使用；它还不是最终批准造型，不复制总览标签、框或无关图标。
- `output:tianhe_ferry_day.png` 固定本轮日常渡口的摄像机、船、码头和岸线；月夜版本只变时间与水面城影。月夜修正版又成为后续残镜异象的早期城影参考，后期整座照川城仍未定稿。
- 依赖状态为 `pending_must_wait` 时不调用相应生图。候选可以作为下一张候选的明确身份／布局锚点，但不能记录为用户已批准最终设计。

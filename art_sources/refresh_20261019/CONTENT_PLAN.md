# 新大纲生图内容与交付顺序

内容依据：[游戏大纲](../../docs/GAME_OUTLINE.md) 第3—16节。本文更新题材、人物经历、场景用途和交付顺序；各类图继续严格执行 [分类风格规范](STYLE_GUIDE.md)、各批 `本批画法`、`references.json` 与已确认样张。人物沿用C版；环境、地图、妖兽、图标、UI、功能插画和特效分别沿用原先对应要求，不新增或替换风格参考。

原尺寸、比例、透明度、帧序、朝向及SVG分层要求继续执行 [通用规则](COMMON_RULES.md)。用户已追加授权继续做完全部图，P0—P3均纳入候选制作；生图目录已联接到D盘，正式替换和游戏规则修改仍另行集成。逐项旧图规格与引用见 [执行规则](PRODUCTION_RULES.md) 和 `PRODUCTION_MANIFEST.json`，实时完成状态见 [全量进度](PROGRESS.md)。历史提示词保留作生成记录，内容与新大纲有差异时修订下一次提示词，画法要求仍沿用原规范。

## 开局内容约束

- 主角16岁、尚未拜师，以无名散修起步。保留已确认主角身份与画法；开局服装、道具不可提前宣告已是青云正式弟子或名门传人。需要适配时交候选说明，不覆盖已确认身份参考。
- 陆承舟初见是客栈抵房钱的富家少爷，入云溪才揭示家世；不能用豪华背景或家徽提前讲完初见悬念。叶知微在集会治伤与争药性；柳寒舟、闻人照在潜龙会或后续入口结识，不强制四人首次拍卖前同框。
- 首次拍卖为历元元年，集会后几天。残镜反应与铜片发热是主线事件；买不起、被别人拍走也能继续，不将拍下残镜画成唯一成立的结果。
- 潜龙会是云溪公共炼气赛事，40岁以下、每5年一届，首届可参赛或观战；陆府夜宴不以夺冠为前提。背景不烘焙冠军姓名、年号、奖励、排行榜或强制胜利姿势。
- 天河渡口属于**白鹭渡**，不是另造一座外海港口。日常渡口与月圆映城保持同一岸线、泊船和视角；倒影中的城与残镜里的照川城是同一座城，初期只露局部，不直接展现封印真相。
- 青云山门教学发生在玩家拜师之后。顾长庚、许清和保留人物身份，不能继续承担强制散修开局的带路情节。

## 场景、地图与地方变化

五城功能遵循大纲3.2、12节：云溪为初阶往来与世家生活；南明为地火、矿材、器坊与修复；沧澜为药材、医修与丹方；北岳为古物、阵法与旧档；望海为海货、航路与海船。沧澜城与沧澜阁、北岳城与玄岳宗分别处理；白鹭渡保持内河身份。青云继续是小宗。中州、北荒、远海和天衍上宗不在首版画假开放地点。

五城相邻关系、路程与盘缠仍待内容校准。08批先交无文字的布局规划；当前可用底图服从实际消费者坐标，新布局另交候选，不能同时做两套互不相容的定稿。五种地点状态为未知、已听闻、已发现、已到访、已探索完毕，由独立UI表达。

闭关场所区分客栈静房、宗门静室、租赁洞府、自有洞府与灵眼／秘境。静房承担最早闭关、领悟与突破，不提前配成可种田炼丹的豪华私府。场景只承担空间与陈设，日租、倍率、按钮和收益由程序显示。

筑基五处探索优先审查已有 `ruin_depths.png`、`wild_spring.png`、`chifeng_cavern.png` 等；需要补图时表现路径、环境障碍、线索和可返回空间，不把所有地方画成斗法台。药路恢复、矿权变化、故地再访等优先用陈设／状态层变化表达。妖蟒、矿区与断剑旧案各有地方解释，不统一加照川城符号。废庙透光、河底石阶、矿洞敲击等是待内容选择的发现示例，不强制各自新增整幅图。

## 照川城线索与揭示边界

按大纲8.2顺序表现：残镜异象 → 白鹭渡月圆城影 → 北岳缺页卷宗与温照衡旧画像 → 沉霞古境实证 → 温照衡口述或遗物日记 → 封存空间 → 阵枢与通路选择。

10批的三拱城门、双水纹、缺口圆环仍是**候选视觉母题**；城名与真相定稿不等于城徽造型获批。初期铜片、残镜、档案和后期阵枢共用同一套母题；02、06、08、09批先引用候选，不各自重造符号。镜子是记录与空间映像，不表现时间旅行。初期素材只露当前已知线索，后期真相说明独立交付。

三条通路各交结果：修复重开表现照川城部分恢复与持续治理；替换旧阵表现救援／疏散、部分区域永久封闭及另修通路；自寻通路表现个人飞升与交托后续责任。公开真相与处理阵枢是两个决定，不把某条通路固定画成隐瞒或公开。可以共用基础空间，不能用一张金色云桥代表全部结局。

## 功法、器物、UI与特效

- 《照水分光诀》：沿用现有图标画法与候选辨识形；表现水金神通连击、善水印转化。初期可出现残篇或演示，完整追求属于五城阶段；不再按旧方案制作蓄势／反击机制。
- 听潮剑：残损与修复是同一器型，分阶段显露能力；水脉附近开局多吸灵气的表现由12批与实际消费者协调，不默认已是本命法宝。
- 《藏息录》：筑基篇的散修传承，表现遁速、撤离和野外避险；不能画成永久隐身或免除一切风险。
- 筑基准备可出现筑基丹或替代天材地宝；结丹及以后不新增“必需突破丹”图像需求。基本准备、可选提升、风险和成果由UI区分，筹划插画不把每件高阶器物都画成必需条件。
- 领悟使用闭关场所中的同一人物与空白部件，文字、玉简栏、日期和出关消息由UI绘制。斗法神通栏为六格，灵气、印与连击标记沿用现有UI／特效画法；格数、读数和操作由程序承担。
- 通用物品、功法、法宝继续用现有SVG部件和生成器；人物C版不扩展为图标或UI风格。第三方CC0特效先审查用途、配色与许可证，不为新剧情强制全部重画。

# 2026-10-19 全资源美术更新规范

用户最新澄清：每一类图片沿用此前对应《觅长生》真实参考和分类样张确定的风格；C 版只指人物，不是全部资源的共同模板。

## 分类标准

| 类型 | 已确定的参考与样张 | 制作要求 |
|---|---|---|
| 人物与动作 | `01_hero`、`02_portrait`，已确认人物 C 版 | 修长造型、漫画五官、发束整体化、简练衣褶、平涂大色块、克制结构阴影；保留身份与道具。动作图集需逐帧可用，不重复静态姿态冒充动画。 |
| 妖兽 | `03_beast` 与原作妖兽参考 | 解剖和轮廓清楚，岩甲／鳞片归并为大块，保留各兽辨识特征，避免密集碎鳞和写实材质。 |
| 城镇与宗门 | `04_location` 与官方城镇／宗门原图 | 建筑按街区或功能组织，清楚轮廓与屋顶色块、群树和远山分层。青云小宗规模必须重新构图。 |
| 舆图 | `05_map` 与官方宁州地图 | 俯视概括地形、小山形与树群、淡色地块、清楚河流；文字、路线、标记由界面绘制，不能烘进底图。 |
| 斗法场地 | `06_battle` 与官方斗法背景 | 前中后景分层，地面留足双方站位，边缘植物分组，避免密集地表纹理。 |
| 室内 | `07_interior` 与室内参考 | 木构与家具组成大块暖色，陈设有序，留出对话空间，避免写实反光和密集木纹。 |
| 物品／功法 | `08_herb`、`09_skill` 与原作小图 | 简练物体剪影和少量明暗，主体比装饰醒目，小尺寸可读；保留原生 SVG 与分层组合，不把完整带框图再次套框。 |
| 面板 | `10_panel` 与任务卷轴参考 | 青绿卷边、纸色阅读区、少量金饰和留白。浅纸面必须配深墨文字；现有深色界面使用同系列深色版本，不能直接套浅纸底造成低对比。 |
| 丹炉／灵田 | `11_furnace`、`12_garden` 与对应系统参考 | 简洁器型和植物群组，减少铭纹、叶脉、泥土碎点；透明资源保留真实 alpha。 |
| 事件 | `13_event` 与原作演出参考 | 图形化构图、云纹与山形分层、象征性焦点；内容服从新大纲，飞升须体现不同通路与结果。 |

## 内容、集成与验收

- 内容依据 `docs/WORLD_STORY_REWRITE_20261019.md`。名称与后期分支尚为暂拟，背景不直接写死文字。
- 当前可用资源按原路径、兼容尺寸替换；场景标签位置单独保存在美术配置中，不改变存档地点 ID。
- 为尚未实现的剧情制作的资源标记为 `ready_for_content`，不能通过添加假的地点／事件宣称已接入。
- 正式素材保存在 `assets/`；生成提示词、来源和覆盖进度保存在本目录；原版备份、生成中间文件和检查图仅放项目 `.tmp/`。
- 位图通过内置 imagegen 制作。原生矢量使用项目生成器维护，不用批量滤镜冒充重绘。
- 所有自动 Godot 验证均使用 `--headless`，检查退出码和 `SCRIPT ERROR`，不启动可见窗口。
- 第三方 CC0 特效属于可复用基础形状，先审查配色和消费者；未重绘的头像、动画与背景如实列入待处理清单。
